# 第二版补充：跨周归一化与经验平台模型

本补充记录的是在原有分周分析之后新增的一组处理。原始第二周厚铅板数据中，40、50、60 片铅板的绝对符合数出现回升；但条件符合比 \(N_{\rm coin}/N_{\rm up}\) 在这三个厚度点基本保持平台。因此，后续综合分析不再只使用绝对符合数的 0 片基准缩放，而是先使用上探测器候选事件数进行条件归一化，再对第二周数据施加原来的 0 片基准缩放因子。

新的综合量定义为

```math
R_{\rm norm}(x)=\frac{N_{\rm coin}(x)}{N_{\rm up}(x)}N_{\rm up}^{\rm W1}(0),
```

其中 \(N_{\rm up}^{\rm W1}(0)=7064\)。为了与原先基于 0 片符合率的跨周标尺保持可比性，第二周数据再乘以

```math
k=\frac{N_{\rm coin}^{\rm W1}(0)}{N_{\rm coin}^{\rm W2}(0)}
=\frac{3357}{1831}=1.833424 .
```

这样得到的“条件归一化后再缩放”的综合计数率为：

| Run | 铅板数 | 厚度(mm) | \(R_{\rm norm}\) | 再乘 \(k\) 后 | 相对第一周0片 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 5181 | 0 | 0 | 3357.00 | 3357.00 | 1.000 |
| 5182 | 10 | 5 | 3146.69 | 3146.69 | 0.937 |
| 5183 | 20 | 10 | 3049.92 | 3049.92 | 0.909 |
| 5184 | 30 | 15 | 2980.19 | 2980.19 | 0.888 |
| 5185 | 40 | 20 | 1641.76 | 3010.05 | 0.897 |
| 5186 | 50 | 25 | 1630.47 | 2989.35 | 0.890 |
| 5187 | 60 | 30 | 1630.01 | 2988.49 | 0.890 |

第二周 0 片 run 51811 的归一化后再缩放结果为 3460.87，高于第一周 0 片的 3357。这个点没有放入 0--60 片趋势拟合，因为它已经被用来定义跨周缩放因子，重复参与拟合会混合校准点和物理趋势点。

这个处理后的曲线显示，第一周 0--15 mm 铅厚范围内符合率下降，而第二周 20--30 mm 厚铅板区间基本进入平台。该结果比原始 \(N_{\rm coin}\) 曲线更能说明：厚铅板区间的绝对计数回升主要与上探测器候选事件规模变化有关，不宜解释为 Rossi 曲线式的物理回升。

对“条件归一化后再缩放”的数据使用两个原文中的经验指数模型。单指数透过率模型为

```math
T(x)=\exp(-x/\lambda_{\rm eff}),
```

拟合得到

```math
\lambda_{\rm eff}=168.57\pm 11.87\ {\rm mm},\qquad
\chi^2/{\rm ndf}=4.973,\qquad R^2=0.333 .
```

单指数计数率模型为

```math
R(x)=R_0\exp(-x/\lambda_{\rm eff}),
```

拟合得到

```math
R_0=3249.64\pm30.27\ {\rm counts/hour},\quad
\lambda_{\rm eff}=243.17\pm38.94\ {\rm mm},
\quad \chi^2/{\rm ndf}=3.514,\quad R^2=0.645 .
```

这两个单指数模型都给出 \(10^2\ {\rm mm}\) 量级的有效衰减长度，但拟合优度并不好。原因不是指数公式本身无法使用，而是当前综合曲线并不是单调、平滑的材料衰减曲线；它包含第一周稳定趋势、第二周基准差异和厚铅板平台三类信息。

为了描述“前段下降、后段平台”的形状，又加入指数加常数模型：

```math
T(x)=T_\infty + A\exp(-x/\lambda_{\rm eff}),
```

对应结果为

```math
T_\infty=0.8862\pm0.0119,\quad
A=0.1144\pm0.0162,\quad
\lambda_{\rm eff}=5.91\pm2.14\ {\rm mm},
\quad \chi^2/{\rm ndf}=0.142,\quad R^2=0.988 .
```

计数率形式

```math
R(x)=R_\infty + A\exp(-x/\lambda_{\rm eff})
```

给出

```math
R_\infty=2974.92\pm40.03\ {\rm counts/hour},\quad
A=384.18\pm54.37\ {\rm counts/hour},\quad
\lambda_{\rm eff}=5.91\pm2.14\ {\rm mm},
\quad \chi^2/{\rm ndf}=0.142,\quad R^2=0.988 .
```

从统计指标看，指数加常数模型明显优于单指数模型。其 AIC 从单指数透过率模型的 31.84、单指数计数率模型的 21.57 降至 6.57；BIC 也降至 6.41。这说明平台模型更贴合当前数据形状。

不过，这个模型是经验描述，不是新的材料吸收定律。它有三个自由参数，而实际用于拟合的数据只有七个点。平台参数 \(T_\infty\) 或 \(R_\infty\) 可以理解为当前装置和归一化方式下厚铅板区间的有效符合率平台；\(\lambda_{\rm eff}=5.91\ {\rm mm}\) 只描述从初始点向平台过渡的快慢，不能解释为铅中 \(\mu\) 子的真实吸收长度。

论文正文中建议把这一部分写成：单指数模型给出有效衰减尺度，但不能很好描述综合曲线；指数加常数模型更符合“下降后趋于平台”的观测形状。由于跨周数据仍存在系统差异，平台模型只能作为经验拟合和图像描述，不应作为精确物理参数。
