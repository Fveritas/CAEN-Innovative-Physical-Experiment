# 第二周数据分析规划

## 1. 分析目标

本阶段只分析第二周数据，即 0、40、50、60 片铅板对应的数据文件。第二周数据内部可以先单独分析，但不能直接与第一周绝对符合率拼接。跨周比较需要在后续单独进行归一化处理。

第二周分析的核心问题是：

> 在第二周实验条件下，厚铅板区域的双探测器符合率、归一化符合比和有效阻挡能力如何随铅板厚度变化？

需要回答的物理问题包括：

1. 40、50、60 片厚铅板下的符合率是否继续下降。
2. 第二周 0 片基准 `51811` 与厚铅板数据之间的相对变化有多大。
3. `Coin/Up` 和 `Coin/Down` 是否提示探测器效率或增益变化。
4. 第二周数据能否为跨周合并提供厚铅板区间趋势。

本分析只使用第二周预处理后的 NumPy 数据：

## 3. 固定阈值与事件定义

本阶段继续使用固定阈值：

```python
area_threshold = 30
area2_threshold = 30
```

符合事件定义为：

```python
coincidence = (area > 30) & (area2 > 30)
```

不进行其他阈值扫描。第二周所有计数率、归一化比值和相对量都基于同一阈值。

## 4. 第二周基础统计

每个 run 需要统计：

| 变量 | 含义 |
| --- | --- |
| `N_total` | 总事件数 |
| `N_up` | 满足 `area > 30` 的事件数 |
| `N_down` | 满足 `area2 > 30` 的事件数 |
| `N_coin` | 同时满足上下阈值的符合事件数 |
| `R_coin` | 符合率，`N_coin / T` |
| `Coin/Up` | 上探测器归一化符合比，`N_coin / N_up` |
| `Coin/Down` | 下探测器归一化符合比，`N_coin / N_down` |

测量时间取：

```text
T = 3600 s
sigma_T = 60 s
```

符合率相对误差：

```text
sigma_R / R_coin = sqrt(1 / N_coin + (60 / 3600)^2)
```

## 5. 第二周相对透过率和阻挡能力

第二周以 `51811.npz` 作为 0 片基准：

```text
Transmission_week2(x) = R_coin_week2(x) / R_coin_week2(0)
Blocking_week2(x) = 1 - Transmission_week2(x)
```

其中 `R_coin_week2(0)` 来自 `51811.npz`。

该阻挡能力表示第二周实验条件下，相对 0 片铅板基准的有效符合率降低。它不是 μ 子的纯吸收概率，而是多重散射、几何符合效率、低能成分衰减和探测器响应共同作用后的有效量。

## 6. 第二周重点诊断

第二周数据需要特别关注系统效应：

1. `N_up`、`N_down` 是否相对 0 片基准有异常变化。
2. `Coin/Up` 和 `Coin/Down` 是否随铅厚变化一致。
3. `area`、`area2` 分布是否显示探测器增益或阈值响应变化。
4. 厚铅板区域是否仍呈现有效符合率下降。

第二周内部结果可以独立讨论，但不要直接和第一周绝对符合率相连。跨周合并时应使用 `Coin/Up` 或 0 片基准缩放。
