# 跨周综合分析规划

## 1. 分析目的

本阶段用于比较第一周和第二周的分析结果，识别两周差异的来源，并为后续是否进行合并分析提供物理和统计依据。

核心问题是：

> 第一周和第二周之间观察到的差异，究竟来自铅板对宇宙线的阻挡作用，还是来自探测器响应、增益、阈值效率、几何对准或采集条件变化？

综合分析不能把所有 run 直接视为同一批稳定条件下的数据。正确流程应为：

1. 先量化两周之间的系统差异。
2. 再判断哪些归一化量可以跨周比较。
3. 最后决定是否可以给出合并趋势，或只能给出分周结果与系统误差讨论。

## 4. 两周不一致的证据

### 4.1 0 片基准符合率偏移

第一周 0 片：

```text
N_coin(5181) = 3357 counts/hour
```

第二周 0 片：

```text
N_coin(51811) = 1831 counts/hour
```

基准比值：

```text
N_coin(51811) / N_coin(5181) = 1831 / 3357 ≈ 0.545
```

这个差异过大，说明两周不在同一个绝对探测尺度上。因此，跨周绝对 `coin/hour` 不能直接拼接。

### 4.2 探测器通过率偏移

第一周 0 片：

```text
N_up / N_total   ≈ 0.531
N_down / N_total ≈ 0.471
Coin/Up          ≈ 0.475
Coin/Down        ≈ 0.536
```

第二周 0 片：

```text
N_up / N_total   ≈ 0.735
N_down / N_total ≈ 0.270
Coin/Up          ≈ 0.267
Coin/Down        ≈ 0.728
```

这说明：

- 第二周上探测器通过率升高。
- 第二周下探测器通过率显著降低。
- `Coin/Up` 明显下降。
- `Coin/Down` 明显升高。

这种变化更像是不对称的探测器响应变化，而不是单纯的宇宙线通量变化。

### 4.3 脉冲积分响应偏移

0 片基准的脉冲积分均值：

| 周次 | Run | `area_mean` | `area2_mean` |
| --- | --- | ---: | ---: |
| 第一周 | `5181` | 36.12 | 34.74 |
| 第二周 | `51811` | 49.06 | 17.71 |

这是探测器响应漂移最直接的证据之一：

- 第二周上探测器响应增强。
- 第二周下探测器响应减弱。
- 固定阈值 `area2 > 30` 在第二周变得更苛刻。

因此，第二周很可能包含下探测器效率或增益变化。

## 5. 需要检验的物理和实验原因

### 5.1 PMT/SiPM 增益漂移

可能来源：

- 温度变化。
- 高压或偏置电压不稳定。
- 光耦合状态变化。
- 电子学增益变化。

典型表现：

```text
area 或 area2 分布整体平移，而没有明确的物理原因。
```

第二周 `area2` 分布偏低，与该可能性一致。

### 5.2 阈值效率变化

由于阈值固定：

```python
area > 30
area2 > 30
```

如果脉冲积分分布发生偏移，固定阈值对应的有效探测效率就会改变。第二周 `area2` 偏低意味着同样的 `area2 > 30` 会筛掉更多下探测器信号。

预期表现：

```text
N_down/N_total 降低
N_coin 降低
Coin/Up 降低
```

这与第二周 0 片数据一致。

### 5.3 几何或对准变化

如果上下探测器相对位置、铅板位置或垂直对准发生变化，几何接受度会改变。

预期表现：

```text
即使单探测器脉冲分布稳定，Coin/Up 和 Coin/Down 也可能变化。
```

因此后续需要同时比较脉冲积分分布和归一化符合比。

### 5.4 环境通量变化

大气压、天气和环境背景可能影响宇宙线通量，但当前 0 片基准差异过大，不太可能仅由普通环境变化解释。环境效应可能存在，但不应作为主要解释。

## 6. 综合分析策略

### 6.1 不直接拼接绝对符合率

以下序列不能直接作为同一条绝对衰减曲线拟合：

```text
5181, 5182, 5183, 5184, 5185, 5186, 5187
```

原因：

```text
第一周和第二周具有不同的 0 片基准和探测器响应。
```

直接对跨周绝对符合率拟合会把铅板衰减和探测器漂移混在一起。

### 6.2 0 片基准缩放

定义：

```text
k = R_coin_week1(0) / R_coin_week2(0)
```

当前数值：

```text
k = 3357 / 1831 ≈ 1.833
```

第二周缩放：

```text
R_coin_week2_scaled(x) = k * R_coin_week2(x)
```

优点：

- 简单直观。
- 报告中容易解释。

局限：

- 假设第二周与第一周只差一个常数效率因子。
- 该假设较强，因为 `area` 和 `area2` 在两周中变化方向不同。

结论：

```text
该方法可作为诊断性归一化，不应作为唯一最终结果。
```

### 6.3 条件符合比归一化

使用：

```text
Coin/Up = N_coin / N_up
```

物理意义：

```text
Coin/Up ≈ P(下探测器也通过阈值 | 上探测器已通过阈值)
```

该量更接近“上探测器已经看到候选事件后，该事件仍能形成双探测器符合的有效概率”。

优点：

- 相比原始 `coin/hour`，对总触发规模变化不那么敏感。
- 比较适合跨周比较。

局限：

- 仍然受到下探测器增益和阈值效率影响。
- 必须结合 `area2` 分布一起解释。

### 6.4 分周透过率曲线

最保守的策略是分别展示：

```text
Week 1 Transmission(x)
Week 2 Transmission(x)
```

每一周都用本周自己的 0 片基准归一化。

优点：

- 不强行假设两周探测器响应完全一致。
- 物理解释更稳健。

局限：

- 不能直接给出单一全局衰减长度。

推荐结论：

```text
两周结果应先作为两个独立测量讨论；跨周归一化结果作为系统误差和趋势比较，而不是决定性的全局拟合。
```

## 7. 建议输出

后续综合分析脚本应生成：

1. 0 片基准对比表：
   - `R_coin(0)`

   - `N_down/N_total`
   - `Coin/Up`
   - `Coin/Down`
   - `area_mean`
   - `area2_mean`

2. 0 片基准诊断图：
   - 第一周 vs 第二周 0 片 `area` 分布。
   - 第一周 vs 第二周 0 片 `area2` 分布。
   - 第一周 vs 第二周 0 片 `area` vs `area2` 二维图。

3. 跨周比较图：
   - 原始 `coin/hour` vs 铅厚度，并标注“不用于物理拟合”。
   - 0 片缩放后的 `coin/hour`。
   - `Coin/Up` vs 铅厚度。
   - 分周 `Transmission` 对比。

4. 系统误差比较表：
   - 原始符合率归一化和 `Coin/Up` 归一化的差异。
   - 两周 0 片探测器响应差异。

## 8. 报告推荐表述

建议写法：

> 两周测量在 0 片铅板基准和探测器脉冲积分分布上存在显著差异。特别是第二周下探测器响应明显降低，使固定阈值 `area2 > 30` 更加严格。因此，两周绝对符合率不能直接拼接成一条衰减曲线。跨周比较应基于 0 片缩放、`Coin/Up` 等归一化量，并将不同归一化策略之间的差异作为系统误差来源。

避免写法：

```text
完整 0-60 片数据直接测量了铅板吸收长度。
```

推荐改为：

```text
完整数据集给出了有效符合率随铅厚变化的趋势，但两周探测器响应变化必须作为系统效应纳入讨论。
```
