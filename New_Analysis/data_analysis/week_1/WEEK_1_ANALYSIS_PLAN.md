# 第一周数据分析规划

## 1. 分析目标

本阶段只分析第一周数据，即 0、10、20、30 片铅板对应的数据文件。第一周数据是在同一周、相近实验条件下采集的，因此可以优先直接比较绝对符合率，不需要引入跨周归一化。

第一周分析的核心问题是：

> 在固定探测器、固定阈值和相同测量时间条件下，宇宙线双探测器符合率如何随铅板厚度变化？

需要回答的物理问题包括：

1. 符合率是否随铅板厚度增加而下降。
2. 如果符合率单调下降，是否可以用多重散射、几何符合效率降低和低能成分衰减来解释。
3. 能否从第一周数据中提取一个有效衰减长度 `lambda_eff`。

这里的 `lambda_eff` 只能解释为当前实验几何、探测阈值和符合条件下的“有效衰减长度”，不能解释为铅对 μ 子的纯吸收长度。

## 3. 固定阈值与事件定义

本阶段统一使用固定阈值：

```python
area_threshold = 30
area2_threshold = 30
```

符合事件定义为：

```python
coincidence = (area > 30) & (area2 > 30)
```

不进行 25/30/35 等不同阈值扫描。所有图表、统计量和拟合都基于同一组阈值，避免人为阈值选择导致结果不可比。

每个 run 需要统计：

| 变量 | 含义 |
| --- | --- |
| `N_total` | 总事件数 |
| `N_up` | 满足 `area > 30` 的事件数 |
| `N_down` | 满足 `area2 > 30` 的事件数 |
| `N_coin` | 同时满足 `area > 30` 和 `area2 > 30` 的符合事件数 |
| `R_coin` | 符合率，`R_coin = N_coin / T` |
| `Coin/Up` | 上探测器归一化符合比，`N_coin / N_up` |
| `Coin/Down` | 下探测器归一化符合比，`N_coin / N_down` |

测量时间 `T` 初步取 1 小时。若后续能从 `TrigtagTime` 或其他记录中可靠得到实际测量时长，再对 `R_coin` 做修正。

## 4. 第一周基础诊断

正式绘制符合率曲线前，应先做数据质量诊断。

### 4.1 事件数检查

检查四个文件的 `N_total` 是否处在合理范围内，并确认没有明显缺失或异常文件。

建议输出表格：

| Run | 铅板数 | 厚度(mm) | `N_total` | `N_up` | `N_down` | `N_coin` |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |

### 4.2 area 和 area2 分布

对每个 run 绘制：

- `area` 一维直方图。
- `area2` 一维直方图。
- `area` vs `area2` 二维分布图。

目的：

1. 检查固定阈值 30 是否位于信号区和低幅噪声区之间。
2. 比较不同铅厚下 `area`、`area2` 分布形状是否明显变化。
3. 确认第一周内部探测器响应相对稳定。

### 4.3 上下探测器通过率

计算：

```text
Up pass fraction = N_up / N_total
Down pass fraction = N_down / N_total
Coin fraction = N_coin / N_total
```

如果 `N_up/N_total` 或 `N_down/N_total` 在第一周内部出现异常跳变，需要在报告中作为数据质量问题说明。

## 5. 符合率分析

### 5.1 主要物理量的含义

第一周分析中最直接、最重要的物理量是双探测器符合计数率：

```text
R_coin = N_coin / T
```

其中 `N_coin` 是同时满足 `area > 30` 和 `area2 > 30` 的事件数，`T` 是测量时间。`R_coin` 表示单位时间内有多少宇宙线事件能够同时被上下探测器记录，因此它反映了当前实验几何和阈值条件下的有效宇宙线符合通量。

辅助物理量包括：

```text
R_up = N_up / T
R_down = N_down / T
Coin/Up = N_coin / N_up
Coin/Down = N_coin / N_down
```

其中 `Coin/Up` 的物理意义可以理解为：

> 已经被上探测器记录到的候选宇宙线事件中，有多大比例也被下探测器记录到。

由于铅板位于上下探测器之间，上探测器可近似作为入射候选事件的监视器，下探测器用于判断粒子是否还能穿过铅板并保持在几何符合范围内。因此 `Coin/Up` 可以反映“穿过铅板后仍能形成双探测器符合的有效概率”。

需要注意：

- `Coin/Up` 不是纯粹的铅吸收概率。
- 它同时受到铅板阻挡、多重散射、几何接收角、下探测器效率和阈值响应影响。
- 第一周内部可以直接比较 `R_coin`，但 `Coin/Up` 仍有助于判断符合率变化是否主要来自几何符合概率变化。

### 5.2 绝对符合率

第一周数据内部可以直接比较绝对符合率：

```text
R_coin = N_coin / T
```

其中 `T = 1 hour` 时，单位可写为 `counts/hour`。如果改用秒，则单位为 Hz。

测量时间取：

```text
T = 1 hour = 3600 s
```

测量时间不确定度取：

```text
sigma_T = 1 min = 60 s
```

符合计数采用泊松统计：

```text
sigma_N = sqrt(N_coin)
```

由于 `R_coin = N_coin / T`，符合率相对误差应同时包含计数误差和时间误差：

```text
sigma_R / R_coin = sqrt(1 / N_coin + (sigma_T / T)^2)
```

代入 `sigma_T / T = 60 / 3600 = 0.0167`：

```text
sigma_R / R_coin = sqrt(1 / N_coin + 0.0167^2)
```

需要绘制：

- 横轴：铅板数或铅厚度。
- 纵轴：`R_coin`。
- 误差棒：`sigma_R`。

### 5.3 相对符合率与阻挡能力

用 0 片铅板的 `5181.npz` 作为第一周基准：

```text
R_rel(x) = R_coin(x) / R_coin(0)
```

其中 `R_coin(0)` 来自 `5181.npz`。

相对符合率的优点是可以更清楚显示铅板导致的比例变化，也方便后续和第二周归一化结果比较。它也可以写成有效透过率：

```text
Transmission(x) = R_coin(x) / R_coin(0)
```

铅板的有效阻挡能力可定义为：

```text
Blocking(x) = 1 - Transmission(x)
```

这个 `Blocking(x)` 表示在当前实验几何、探测阈值和符合判据下，有效符合率相对 0 片基准降低了多少。报告中应写成“有效符合率降低”或“有效阻挡能力”，不要直接写成“μ 子被吸收了多少”，因为符合率下降可能来自：

- μ 子多重散射后偏离下探测器。
- 低能电子、强子等非 μ 成分被铅板削弱。
- 部分粒子能量损失后低于探测阈值。
- 探测器几何符合效率变化。

相对符合率的误差可近似传播为：

```text
sigma_Rrel / R_rel =
sqrt(1 / N_coin(x) + 1 / N_coin(0) + (60 / 3600)^2 + (60 / 3600)^2)
```

其中时间误差部分约为：

```text
sqrt(2) * 1.67% = 2.36%
```

需要绘制：

- 横轴：铅板数、厚度 mm 或辐射长度 `X/X0`。
- 纵轴：`R_rel`。
- 0 片点应归一化为 1。
- 可额外绘制 `Blocking(x)`，用于直观展示铅板阻挡能力。

### 5.4 Coin/Up 和 Coin/Down

虽然第一周可以直接比较绝对符合率，但仍建议计算：

```text
Coin/Up = N_coin / N_up
Coin/Down = N_coin / N_down
```

用途：

1. 检查第一周内部上下探测器响应是否稳定。
2. 为后续第二周和跨周分析提供一致的统计量。
3. 判断符合率下降是否主要来自单探测器通过率变化，还是来自双探测器几何符合概率变化。

## 6. 衰减拟合

### 6.1 拟合模型

对第一周的符合率或相对符合率尝试指数模型：

```text
N(x) = N0 * exp(-x / lambda_eff)
```

或对相对符合率写为：

```text
R_rel(x) = exp(-x / lambda_eff)
```

其中：

- `x` 可取铅厚度，单位 mm。
- `lambda_eff` 为有效衰减长度，单位 mm。

### 6.2 拟合注意事项

第一周只有 4 个厚度点，拟合自由度很少，因此拟合结果应谨慎解释。

报告中应写清楚：

- 指数模型只是经验性描述。
- `lambda_eff` 不是 μ 子在铅中的真实吸收长度。
- 该参数包含多重散射、几何接收角、能量损失、非 μ 成分衰减和探测器响应等综合影响。

### 6.3 拟合输出

建议记录：

| 参数 | 含义 |
| --- | --- |
| `N0` 或固定基准 | 0 片铅板处的归一化计数 |
| `lambda_eff` | 有效衰减长度 |
| `sigma_lambda` | 拟合误差 |
| `chi2/ndf` | 拟合优度 |

若拟合不稳定，应在报告中说明“数据点较少，拟合仅用于给出趋势尺度”。

## 7. 能谱与脉冲积分分析

除了计数率，还应比较不同铅厚下的 `area` 和 `area2` 分布。

建议图表：

1. 四个 run 的 `area` 直方图叠加。
2. 四个 run 的 `area2` 直方图叠加。
3. 只对符合事件绘制 `area` 分布。
4. 只对符合事件绘制 `area2` 分布。

观察重点：

- 铅板增加后，低积分事件是否减少。
- 能谱峰位是否移动。
- 上下探测器分布是否在第一周内部保持一致。

注意：`area` 和 `area2` 是脉冲积分量，与沉积能量相关，但若没有能量刻度，不能直接写成绝对能量谱。报告中应称为“脉冲积分分布”或“相对能量响应分布”。

## 9. 报告中第一周部分的写法

第一周结果在报告中可按以下逻辑展开：

1. 说明第一周数据包含 0、10、20、30 片铅板，测量条件相对一致。
2. 说明固定阈值和符合事件定义。
3. 给出基础统计表。
4. 展示符合率随铅厚变化的图。
5. 展示相对符合率和有效阻挡能力曲线。
6. 解释 `Coin/Up` 的条件概率意义，并说明它不是纯吸收概率。
7. 给出指数拟合结果，并强调其为有效衰减长度。
8. 结合多重散射、低能成分衰减和几何符合效率解释曲线形状。

建议结论表述：

> 第一周数据在相同实验条件下显示，随着铅板厚度从 0 增加到 15 mm，双探测器符合率呈现随厚度变化的趋势。若结果表现为单调下降，则说明在本实验几何条件下，多重散射和几何符合效率降低可能是重要影响因素。因此第一周数据可用于提取一个实验条件相关的有效衰减尺度，但不能直接解释为 μ 子在铅中的纯吸收长度。
