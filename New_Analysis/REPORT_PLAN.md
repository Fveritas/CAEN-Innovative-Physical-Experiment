# 宇宙线铅板阻挡实验报告规划

## 1. 报告定位与核心问题

本报告按“小论文式课程实验报告”组织，重点不是单纯罗列数据处理步骤，而是围绕一个明确的物理问题展开：

> 宇宙线穿过不同厚度铅板后，双探测器符合率如何变化？这种变化主要来自铅板中的能量损失、多重散射、次级粒子产生，还是实验系统探测效率变化？

报告的主线应分为三层：

1. 第一周数据单独分析。
2. 第二周数据单独分析。
3. 两周数据经过归一化后合并讨论。

由于两周测量条件存在系统差异，尤其是探测器增益或探测效率可能变化，因此不能直接把两周的绝对符合率拼接成一条曲线。合并分析必须引入归一化方法，并把归一化前后的差异作为系统误差讨论的一部分。

速度测量不是报告主线。普通 ROOT 文件中没有完整的双通道时间字段，只有 `Raw_data/add_time_5181b/5181b.root` 适合做时间差分析。因此速度测量最多作为附录或简短补充。

## 3. 数据处理流程

### 3.1 ROOT 数据读取

每个 ROOT 文件包含 `t1` tree。主要使用以下变量：

- `area`：上探测器脉冲积分。
- `area2`：下探测器脉冲积分。
- `Index_minamp`：普通文件中的时间相关字段。
- `Index_minamp1`、`Index_minamp2`：仅时间校准文件 `5181b.root` 中存在。

正式分析时应优先读取最少必要分支，避免一次性加载无关字段。

### 3.2 符合事件选择

初始符合判据采用：

```python
coincidence = (area > 30) & (area2 > 30)
```

每个文件需要统计：

- 总事件数 `N_total`
- 上探测器通过阈值数 `N_up`
- 下探测器通过阈值数 `N_down`
- 符合事件数 `N_coin`
- 符合率 `R_coin = N_coin / T`
- 上探测器归一化符合比 `Coin/Up = N_coin / N_up`
- 下探测器归一化符合比 `Coin/Down = N_coin / N_down`

其中测量时间 `T` 初步取 1 小时。若后续从 `TrigtagTime` 中能可靠得到实际采集时长，则应使用实际时长修正。

### 3.3 误差估计

符合计数采用泊松统计：

```text
sigma_N = sqrt(N_coin)
```

符合率误差：

```text
sigma_R = sqrt(N_coin) / T
```

比值误差用误差传播估计。若采用 `Coin/Up`，可以近似写为：

```text
sigma(Coin/Up) ~= (Coin/Up) * sqrt(1/N_coin + 1/N_up)
```

该公式忽略了 `N_coin` 与 `N_up` 的相关性，报告中可说明这是保守估计；若需要更严谨，可使用二项分布误差：

```text
sigma_p = sqrt(p * (1 - p) / N_up)
```

其中 `p = N_coin / N_up`。

### 3.4 阈值选择说明

本实验报告统一采用固定阈值 `area > 30`、`area2 > 30` 作为符合事件选择标准。后续所有计数率、归一化比值和曲线拟合都应基于同一阈值，避免不同阈值选择引入额外的人为差异。

## 4. 第一周数据分析

第一周数据包括 0、10、20、30 片铅板，内部测量条件相对一致，因此可以直接比较绝对符合率。

应完成以下分析：

1. 用 `5181.root` 作为第一周 0 片基准。
2. 计算 `5181.root`、`5182.root`、`5183.root`、`5184.root` 的符合数和符合率。
3. 绘制第一周 `R_coin` vs 铅板厚度曲线。
4. 绘制第一周相对符合率：

```text
R_rel(x) = R_coin(x) / R_coin(0)
```

5. 尝试指数衰减拟合：

```text
N(x) = N0 * exp(-x / lambda_eff)
```

其中 `lambda_eff` 只能解释为“有效衰减长度”，不能解释为纯吸收长度，因为实验几何、多重散射和探测效率都会影响符合率。

第一周讨论重点：

- 0 到 30 片铅板范围内，符合率是否单调下降。
- 在 2 到 3 个辐射长度附近是否出现 Rossi 峰。
- 如果没有明显 Rossi 峰，应解释为探测器几何接收角较小，多重散射可能使粒子偏离双探测器符合路径。

## 5. 第二周数据分析

第二周数据包括 0、40、50、60 片铅板，内部同样应先单独讨论。

应完成以下分析：

1. 用 `51811.root` 作为第二周 0 片基准。
2. 计算 `51811.root`、`5185.root`、`5186.root`、`5187.root` 的符合数和符合率。
3. 绘制第二周 `R_coin` vs 铅板厚度曲线。
4. 绘制第二周相对符合率：

```text
R_rel_week2(x) = R_coin_week2(x) / R_coin_week2(0)
```

5. 检查第二周的 `N_up`、`N_down`、`Coin/Up`、`Coin/Down` 是否显示探测器效率或增益变化。

第二周讨论重点：

- 厚铅板区间的符合率是否继续下降。
- 下探测器效率变化是否明显。
- 第二周绝对符合率不能直接和第一周拼接，需要归一化。

## 6. 两周数据合并策略

### 6.1 合并问题的来源

两周测量可能存在以下系统差异：

- PMT/SiPM 增益变化。
- 温度或高压稳定性变化。
- 探测器位置或铅板位置微调。
- 环境本底变化。
- 下探测器效率降低。

因此，直接比较第一周和第二周的绝对符合率是不严谨的。

### 6.2 主方法：Coin/Up 归一化

主图建议使用：

```text
P_coin|up = N_coin / N_up
```

物理含义：

- `N_up` 近似代表上探测器看到的入射候选事件数。
- `N_coin/N_up` 代表这些候选事件同时被下探测器记录的概率。
- 该比值可以部分抵消总触发率、宇宙线通量和上游探测效率变化。

使用方式：

1. 对所有文件计算 `Coin/Up`。
2. 绘制 `Coin/Up` vs 铅板厚度。
3. 第一周和第二周数据放在同一图中，但用不同颜色或 marker 区分。
4. 以 `Coin/Up` 的变化趋势作为合并 Rossi 曲线的主结果。

### 6.3 辅助方法：0 片基准缩放

用两周 0 片数据估计周间归一化系数：

```text
k = R_coin_week1(0) / R_coin_week2(0)
```

然后对第二周绝对符合率做缩放：

```text
R_coin_week2_scaled(x) = k * R_coin_week2(x)
```

使用方式：

1. 将缩放后的第二周数据和第一周数据画在同一张图。
2. 与 `Coin/Up` 主方法比较。
3. 如果两种方法趋势一致，说明铅厚导致的变化较可信。
4. 如果两种方法差异明显，应把差异作为系统误差，不强行给出过精确的统一衰减参数。

### 6.4 合并结论表达原则

合并分析中应避免过度声称：

- 不应说“精确测得铅对 μ 子的吸收长度”。
- 应说“测得该实验几何和阈值条件下的有效符合率衰减”。
- 应强调该衰减包含物理过程和探测系统响应两部分。

## 7. 物理概念与解释框架

### 7.1 宇宙线与 μ 子

海平面宇宙线中，能穿透到实验室的主要带电粒子是 μ 子。μ 子通常具有 GeV 量级能量，因此几厘米铅板不会简单地完全吸收 μ 子。

报告中应强调：

- μ 子穿透能力强。
- 铅板导致的符合率下降不一定来自 μ 子被完全吸收。
- 多重散射使粒子偏离原方向，从而逃出上下探测器的几何符合范围，是重要机制。

### 7.2 电离能量损失

μ 子在物质中主要通过电离损失能量。典型能损数量级可参考：

```text
dE/dx ~ 1-2 MeV/(g/cm^2)
```

对于铅：

```text
质量厚度 = rho * x
```

其中 `rho = 11.34 g/cm^3`，`x` 为铅厚度。30 mm 铅约对应：

```text
3.0 cm * 11.34 g/cm^3 = 34.02 g/cm^2
```

对应电离能损大约几十 MeV。相对于 GeV μ 子，这不足以解释所有符合率下降，因此要讨论多重散射和非 μ 成分。

### 7.3 多重散射

带电粒子穿过铅时会发生多重库仑散射。铅的辐射长度较短，厚度达到几个 `X0` 后，散射角会明显增加。

在本实验中，上下探测器面积有限且间距有限，多重散射会使粒子路径偏离下探测器，从而降低符合率。这是解释单调衰减的重要物理机制。

### 7.4 Rossi 转换曲线

Rossi 曲线描述宇宙线穿过吸收体后计数率随厚度的变化。理想情况下，薄到中等厚度区域可能因为次级粒子产生而出现计数增强或峰值；厚吸收体区域则由于吸收和散射导致计数下降。

本实验中如果没有明显峰值，可从以下角度解释：

- 探测器几何接收角有限。
- 双探测器符合要求抑制了偏离路径的次级粒子。
- 铅板厚度点数较少。
- 两周数据存在系统差异。
- 主导观测量是符合效率，而不是单探测器粒子通量。

### 7.5 探测效率与系统误差

PMT/SiPM 探测能力变化会改变 `area`、`area2` 分布，从而影响阈值通过率和符合率。报告中应把这类变化作为系统误差讨论，而不是简单当作铅板效应。

重点检查：

- 两周 0 片数据的 `area`、`area2` 分布是否不同。
- `N_up` 与 `N_down` 是否有明显相对变化。
- `Coin/Up` 与 `Coin/Down` 哪个更稳定。
- 固定阈值 `area > 30`、`area2 > 30` 下，两周 0 片数据的阈值通过率是否存在系统差异。

## 12. 写作结论的预期方向

最终结论应围绕以下几点组织：

1. 符合率随铅板厚度整体下降。
2. 两周绝对符合率存在系统差异，说明探测效率或实验条件发生变化。
3. 使用 `Coin/Up` 和 0 片基准缩放后，可以得到更合理的合并趋势。
4. 未必能观察到明显 Rossi 峰；若没有峰值，这是合理结果，不代表实验失败。
5. 本实验测得的是当前几何、阈值和探测效率条件下的有效符合率衰减。
6. 多重散射、低能成分衰减和探测系统效率变化共同影响观测结果。
