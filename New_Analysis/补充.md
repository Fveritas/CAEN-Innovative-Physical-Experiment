#### SiPM实验物理原理学习笔记

SiPM实验可以理解为一条完整的信号转换链：

```text
LED光脉冲
  -> SiPM吸收入射光子
  -> 产生光电子
  -> 微单元发生雪崩倍增
  -> 输出电流/电压脉冲
  -> 数字化仪记录波形
  -> 对波形积分得到area
  -> 多次事件形成area分布和光电子峰
```

##### 1. SiPM测量的对象

SiPM（Silicon Photomultiplier，硅光电倍增管）不是直接“看见光子数”，而是把入射光子转换成电信号。SiPM由许多微小的雪崩二极管单元组成，每个微单元工作在Geiger模式。

当一个光子被SiPM吸收并产生电子-空穴对时，它可能触发一个微单元发生雪崩。一次雪崩会释放近似固定的一份电荷。因此，在弱光条件下：

- 0个光电子触发时，主要记录到基线和暗噪声；
- 1个光电子触发时，输出约一份固定电荷；
- 2个光电子触发时，输出约两份固定电荷；
- 3个光电子触发时，输出约三份固定电荷。

所以，SiPM的输出信号在合适条件下会表现出一个个分立的光电子峰。

##### 2. area的积分含义

数字化仪记录的是一次事件的电压波形，而不是单个数值。设波形为：

```math
V(t)
```

没有信号时，电子学系统本身有一个基线：

```math
V_{\rm baseline}
```

因此，脉冲积分量area通常可以理解为：

```math
\mathrm{area}\sim\int [V(t)-V_{\rm baseline}]\,dt
```

也就是说，area表示把一次脉冲在时间窗口内“加起来”得到的面积。它的物理意义不是粒子的真实能量，也不是光子数本身，而是该次脉冲对应的总电荷量的电子学表征。

电流和电荷满足：

```math
I(t)=\frac{dQ}{dt}
```

所以总电荷为：

```math
Q=\int I(t)\,dt
```

如果电子学前端的等效阻抗为R，并且电压信号满足：

```math
V(t)=I(t)R
```

那么：

```math
Q=\frac{1}{R}\int V(t)\,dt
```

因此，对电压波形积分，本质上是在估计这次脉冲通过电子学系统的总电荷量。这就是area的核心含义：它是电荷积分在数字化波形中的表现。

##### 3. 光电子峰的物理含义

在弱光LED实验中，每一次LED脉冲中被SiPM探测到的光电子数并不固定，而是有统计涨落。一次脉冲可能产生0个、1个、2个或更多光电子。

如果每个光电子触发的微单元释放近似相同的电荷，那么不同光电子数会对应不同的area：

```math
\mathrm{Area}_0,\ \mathrm{Area}_1,\ \mathrm{Area}_2,\ \mathrm{Area}_3,\cdots
```

这些不同的area在直方图中表现为不同的峰：

- 0光电子峰：主要对应基线、暗噪声和无真实光信号事件；
- 1光电子峰：一个微单元被触发；
- 2光电子峰：两个微单元被触发；
- 3光电子峰：三个微单元被触发；
- 更高光电子峰：更多微单元被触发。

所以，光电子峰序号本质上近似表示被探测到的光电子数，也可以近似理解为被触发的微单元数。

##### 3.1 低area高峰与基线/基座峰

在area分布中，横坐标很小、计数很高的峰通常可以理解为低积分量事件峰。更准确地说，它不是“基线本身”，而是基线涨落、暗噪声、小脉冲以及没有形成明显有效信号的事件共同构成的积分分布峰。在探测器实验中，这类峰常称为pedestal peak，也就是基座峰或零光电子峰。

从积分定义看：

```math
\mathrm{area}\sim\int [V(t)-V_{\rm baseline}]\,dt
```

如果某次事件中没有明显的真实脉冲，或者只有很小的电子学波动，那么扣除基线后的积分量仍然接近零，于是这些事件会集中在area较小的位置。由于无信号事件、暗噪声事件和低幅度毛刺数量通常较多，所以该区域可能形成一个很高的峰。

因此，低area高峰可以近似理解为：

```text
低area高峰 ≈ 基线涨落 + 暗噪声 + 小毛刺 + 零光电子/无有效信号事件
```

它可以作为判断阈值选择是否合理的重要参照。设置`area > 30`这类阈值的一个目的，就是把低area基座峰切掉，只保留更可能对应真实有效信号的事件。

但是需要注意：如果探测器增益降低或响应整体左移，真实信号峰也可能向低area区域移动，甚至靠近阈值以下。此时固定阈值`area > 30`不再只是切除噪声，也可能误删一部分真实信号事件。因此，遇到不同run或不同周的area分布差异时，应通过阈值扫描检查计数结果是否随阈值变化。本实验后续检查发现，改变阈值后符合计数基本没有变化，说明当前`area2`分布差异更可能来自设备参数或积分尺度设置差异，而不是导致结果变化的有效阈值效应。

##### 4. 峰位置与光电子数的线性关系

实验中所说的线性关系主要是：

```math
\mathrm{Area}_n=A_0+n\Delta A
```

其中：

- n是光电子峰序号，取0、1、2、3等；
- `Area_n`是第n个光电子峰的位置；
- `A_0`是0光电子峰位置，对应基线或零点偏移；
- `Delta A`是相邻光电子峰之间的间距。

这个线性关系的物理含义是：

> 每增加一个被探测到的光电子，SiPM输出脉冲的积分电荷就增加近似固定的一份。

因此，线性拟合的斜率`Delta A`代表单个光电子对area的平均贡献，也就是实验意义上的单光电子增益。截距`A_0`代表零光电子基线位置。拟合优度R^2越接近1，说明峰位置与峰序号之间越接近线性关系，SiPM的光电子数分辨能力越好。

##### 5. 增益Gain的影响

增益可以理解为“一个光电子触发后，被放大成多大的电信号”。SiPM增益通常与偏置电压有关。偏置电压越高，超过击穿电压的过压越大，单次雪崩释放的电荷越多。

增益增大时：

- 单个光电子对应的输出电荷增大；
- area分布中相邻光电子峰的间距变大；
- 峰位置整体向更大的area移动；
- `Area_n`对峰序号n线性拟合的斜率变大。

增益降低时：

- 单光电子信号变弱；
- 相邻光电子峰间距变小；
- 峰之间可能更难分辨。

所以，增益改变的是“每个光电子贡献多大的信号”，而不是每次LED脉冲中有多少个光电子。

##### 6. 光强Light的影响

光强改变的是每次LED脉冲中入射到SiPM上的平均光子数，也就是平均光电子数。若平均光电子数为：

```math
\mu
```

则探测到n个光电子的概率可近似服从泊松分布：

```math
P(n)=\frac{\mu^n e^{-\mu}}{n!}
```

光强增大时，泊松分布的均值增大。因此：

- 0光电子峰和1光电子峰的相对高度降低；
- 2、3、4个及更高光电子峰的相对高度升高；
- 整个area分布的重心向右移动；
- 但相邻峰的位置和间距基本不变。

这说明光强主要改变“每次脉冲中有多少个光电子”，而不改变“每个光电子贡献多大的电荷”。

##### 7. 阈值Threshold的影响

阈值是电子学判选电路的门槛。只有信号幅度或积分量超过设定阈值的事件，才会被记录或被认为有效。

阈值主要影响低area区域：

- 阈值升高时，暗噪声、小毛刺和弱信号会被截断；
- 0光电子峰和较弱的1光电子峰可能减少甚至消失；
- 噪声抑制效果增强；
- 但真实的弱光信号也可能被误删。

阈值降低时：

- 更多弱信号可以被保留下来；
- 但暗电流噪声和电子学噪声也更容易进入数据；
- 低area区域可能出现更多噪声事件。

因此，阈值改变的是“哪些事件能够进入样本”，尤其决定低幅度信号和噪声事件的保留比例。

##### 8. 三个变量的核心区别

| 参数 | 改变的对象 | 图像上的表现 | 核心物理含义 |
|---|---|---|---|
| 增益Gain | 单个光电子的输出电荷 | 峰间距变大或变小 | 每个光电子信号大小改变 |
| 光强Light | 平均光电子数 | 各峰高度比例改变 | 泊松分布均值改变 |
| 阈值Threshold | 事件保留门槛 | 低area区域被截断 | 弱信号和噪声筛选改变 |

可以简单记为：

- 增益改变“每个光电子有多大”；
- 光强改变“一次有多少个光电子”；
- 阈值改变“哪些事件能被留下”。

##### 9. 与宇宙线铅板实验的联系

宇宙线铅板实验中使用固定条件：

```math
(\mathrm{area}>30)\land(\mathrm{area2}>30)
```

定义上下探测器符合事件。这个条件看起来只是数据筛选，但SiPM前置实验说明，area阈值背后有明确的探测器物理含义。

如果SiPM增益稳定，那么固定阈值可以作为稳定的信号选择条件。可是如果某一通道增益降低、基线变化或电子学状态漂移，同样的物理信号会对应更小的area。此时固定阈值`area > 30`或`area2 > 30`就会变得更严格，导致有效探测效率下降。

因此，宇宙线实验中符合数下降不一定全部来自铅板阻挡，也可能来自探测器响应或采集参数变化。不过这种判断必须经过阈值敏感性检查。本实验改变阈值后主要符合计数没有明显变化，说明`area2`分布差异虽然提示设备参数设置不同，但不应被解释为影响本次结果的主要阈值效率效应。


### 2.对铅板实验的补充

#### 计数率、符合计数率与Hz单位

老师PPT中的`Count Rate`通常指计数率，也就是单位时间内探测器记录到的事件数。计数率的国际单位可以写成：

```math
\mathrm{s^{-1}}
```

也就是Hz：

```math
1\ \mathrm{Hz}=1\ \mathrm{s^{-1}}=1\ \mathrm{count/s}
```

因此，Hz在这里不是指周期振荡频率，而是指“每秒记录多少个事件”。

如果只讨论单个探测器的计数率，可以定义：

```math
R_{\rm up}=\frac{N_{\rm up}}{T}
```

```math
R_{\rm down}=\frac{N_{\rm down}}{T}
```

其中：

- `N_up`表示上探测器中满足阈值条件的事件数；
- `N_down`表示下探测器中满足阈值条件的事件数；
- `T`表示测量时间；
- `R_up`和`R_down`分别表示上、下探测器的单通道计数率，单位可以写作Hz。

如果讨论上下探测器同时记录到的符合事件，则定义符合事件数：

```math
N_{\rm coin}
=\#[(\mathrm{area}>30)\land(\mathrm{area2}>30)]
```

对应的符合计数率为：

```math
R_{\rm coin}=\frac{N_{\rm coin}}{T}
```

其中：

- `N_coin`表示同时满足上探测器`area > 30`和下探测器`area2 > 30`的事件数；
- `R_coin`表示双探测器符合计数率，也可以称为符合率；
- `T`是该run的测量时间。

所以，`R_coin`本质上就是符合事件的`Count Rate`。如果老师PPT中的`Count Rate`指的是双探测器符合事件，那么它就对应本文中的`R_coin`；如果PPT中指的是单个探测器事件，则对应`R_up`或`R_down`。

本实验中每个run的测量时间约为1小时，即：

```math
T=3600\ \mathrm{s}
```

如果某个run中测得：

```math
N_{\rm coin}=3357
```

则：

```math
R_{\rm coin}
=\frac{3357}{3600}\ \mathrm{s^{-1}}
\approx 0.9325\ \mathrm{Hz}
```

也就是说：

```math
3357\ \mathrm{counts/hour}\approx 0.93\ \mathrm{Hz}
```

因此，`counts/hour`和Hz只是计数率的不同单位表示。`counts/hour`适合直接展示一小时采集到的总符合数；Hz则是标准的每秒计数率单位。

需要注意的是，`R_coin`不是纯粹的宇宙线入射通量，而是固定几何、固定阈值和实际探测器效率条件下的有效符合计数率。它可以形式上理解为：

```math
R_{\rm coin}
\sim
\Phi A_{\rm geom}\epsilon_{\rm up}\epsilon_{\rm down}P_{\rm eff}(x)
```

其中：

- `Phi`表示入射宇宙线通量；
- `A_geom`表示上下探测器的几何接受度；
- `epsilon_up`和`epsilon_down`表示上、下探测器有效探测效率；
- `P_eff(x)`表示铅板厚度为`x`时，粒子仍能形成有效符合事件的概率。

因此，`R_coin`随铅板厚度下降，可能来自铅板造成的能损和多重散射，也可能来自探测器响应变化、阈值效率变化或几何条件变化。论文中应将它称为“有效符合计数率”，避免直接解释为宇宙线本身的真实通量。

#### 单通道计数与双通道符合计数的修改建议

初稿中关于单通道计数和双通道符合计数的基本判断是正确的，但需要更明确地贴合本实验实际。本实验实际采用双通道符合计数作为主要观测量，其中`area`对应上探测器通道，`area2`对应下探测器通道。单通道计数只是辅助诊断量，用于检查每个通道自身的触发状态和响应变化。

建议将原文相关段落改写为：

```latex
本实验实际采用双通道符合计数作为主要观测量。上、下两个探测器的脉冲积分量分别记为 \(\mathrm{area}\) 和 \(\mathrm{area2}\)，其中 \(\mathrm{area}\) 对应上探测器通道，\(\mathrm{area2}\) 对应下探测器通道。单通道计数可分别定义为
\[
N_{\rm up}=\#(\mathrm{area}>30),\qquad
N_{\rm down}=\#(\mathrm{area2}>30).
\]
它们主要反映各自通道的触发效率、噪声水平和入射事件规模。本文的主要分析量为双通道符合计数
\[
N_{\rm coin}
=
\#[(\mathrm{area}>30)\land(\mathrm{area2}>30)].
\]
该量要求同一事件在上下两个探测器中均产生超过阈值的脉冲积分信号，因此比单通道计数更能代表穿过整个实验装置的有效宇宙线事件。与此同时，\(N_{\rm coin}\) 也更容易受到任一通道探测效率、增益漂移、阈值响应或采集参数变化的影响。若某一通道的 \(\mathrm{area}\) 分布发生变化，应通过阈值扫描检查这种变化是否真的改变符合计数。本实验改变阈值后符合计数基本不变，说明当前 \(\mathrm{area2}\) 分布差异不应作为影响结果的主要原因。
```

这段文字需要强调三个点：

- `area`是上探测器通道，`area2`是下探测器通道；
- 论文主观测量不是单通道计数，而是双通道符合计数`N_coin`；
- `N_coin`更接近穿过整个装置的有效宇宙线事件，但也更容易受到任一通道效率、采集参数或阈值选择变化的影响；本实验的阈值扫描显示，`area2`分布差异对当前符合计数没有实质影响。

#### 数据与处理方法的逻辑

论文中“数据与处理方法”部分的核心作用，是说明原始实验数据如何转化为符合数、符合计数率、透过率、阻挡率、拟合曲线以及系统误差判断。整个流程可以概括为：

```text
ROOT原始数据
  -> 读取事件分支
  -> 提取area、area2等变量
  -> 用固定阈值筛选事件
  -> 统计单通道计数和双通道符合计数
  -> 计算计数率、透过率、阻挡率
  -> 分周拟合有效衰减模型
  -> 对比0片基准和area2分布
  -> 判断是否可以跨周合并
```

##### 1. 原始数据

实验采集得到的原始数据为ROOT文件。ROOT是粒子物理实验中常用的数据格式，适合保存大量事件级数据。每一个事件中包含若干波形或波形处理后的变量，例如：

- `area`：上探测器通道的脉冲积分量；
- `area2`：下探测器通道的脉冲积分量；
- `amp`：脉冲幅度；
- `base`：波形基线；
- `rms`：基线噪声或波形涨落尺度；
- `Index_minamp`：与波形最小幅度位置相关的索引量。

本文最主要使用的是`area`和`area2`，因为它们直接决定事件是否通过上下探测器的固定阈值。

##### 2. 预处理

ROOT文件不适合每次画图和拟合时反复读取，因此可以先用`uproot`读取ROOT数据，再保存为轻量化的NumPy文件，例如`.npz`文件。

预处理的目的不是改变数据，而是提取后续分析需要的事件级变量。这样做有几个好处：

- 避免每次分析都重新解析ROOT文件；
- 提高统计、拟合和画图速度；
- 保证每个run使用同一套变量和筛选规则；
- 使后续分析流程更容易复现。

##### 3. 固定阈值筛选

本实验采用固定阈值：

```math
\mathrm{area}>30,\qquad \mathrm{area2}>30
```

由此定义单通道计数：

```math
N_{\rm up}=\#(\mathrm{area}>30)
```

```math
N_{\rm down}=\#(\mathrm{area2}>30)
```

以及双通道符合计数：

```math
N_{\rm coin}
=
\#[(\mathrm{area}>30)\land(\mathrm{area2}>30)]
```

其中`#`表示满足条件的事件个数。`N_coin`是本实验的主要观测量，因为它表示同一事件在上下两个探测器中都产生了超过阈值的有效信号。

##### 4. 符合计数率

每个run的测量时间约为：

```math
T=3600\ \mathrm{s}
```

因此符合计数率为：

```math
R_{\rm coin}=\frac{N_{\rm coin}}{T}
```

如果用`counts/hour`表示，由于每个run约为一小时，数值上近似等于`N_coin`。例如：

```math
N_{\rm coin}=3357
```

则：

```math
R_{\rm coin}
=\frac{3357}{3600}
\approx0.9325\ \mathrm{Hz}
```

也可以写作：

```math
3357\ \mathrm{counts/hour}
```

##### 5. 相对透过率和阻挡率

为了比较不同铅板厚度下符合率的变化，以同一周0片铅板数据作为基准，定义相对透过率：

```math
\mathcal{T}(x)=\frac{R_{\rm coin}(x)}{R_{\rm coin}(0)}
```

如果不同run的测量时间相同或近似相同，也可以近似写成：

```math
\mathcal{T}(x)\approx
\frac{N_{\rm coin}(x)}{N_{\rm coin}(0)}
```

有效阻挡率定义为：

```math
\mathcal{B}(x)=1-\mathcal{T}(x)
```

例如第一周30片铅板：

```math
\mathcal{T}
=\frac{3046}{3357}
\approx0.907
```

```math
\mathcal{B}
=1-0.907
\approx0.093
```

这表示在`15 mm`铅厚下，本实验装置记录到的双探测器有效符合事件减少约`9.3%`。这个数值应理解为有效符合率下降，而不是纯粹的`\mu`子吸收率。

##### 6. 分周分析的必要性

实验数据分两周采集。第一周包含：

```math
0,\ 10,\ 20,\ 30
```

片铅板，对应：

```math
0,\ 5,\ 10,\ 15\ \mathrm{mm}
```

第二周包含：

```math
0,\ 40,\ 50,\ 60
```

片铅板，对应：

```math
0,\ 20,\ 25,\ 30\ \mathrm{mm}
```

如果两周探测器状态完全相同，原则上可以把两周数据拼接为一条厚度曲线。但实际数据表明，两周0片基准差异很大：

```math
N_{\rm coin}^{\rm W1}(0)=3357
```

```math
N_{\rm coin}^{\rm W2}(0)=1831
```

同时，两周0片基准存在显著差异，需要检查通量、几何摆放、采集参数和探测器状态等系统因素。虽然`area2`分布存在差异，但阈值扫描显示改变阈值后符合计数基本没有变化，因此该分布差异更应作为设备参数或积分尺度差异的诊断现象，而不是导致结果变化的主要原因。数据处理仍应采用“先分周分析，再讨论跨周归一化或合并”的策略。

##### 7. 有效衰减模型拟合

为了描述符合率随铅板厚度下降的趋势，可以使用经验指数模型：

```math
\mathcal{T}(x)=\exp(-x/\lambda_{\rm eff})
```

也可以直接拟合绝对符合计数率：

```math
R_{\rm coin}(x)
=
R_0\exp(-x/\lambda_{\rm eff})
```

其中`\lambda_eff`是有效衰减长度。它不是铅中`\mu`子的真实吸收长度，而是包含：

- 能量损失；
- 多重散射；
- 几何接受度；
- 探测器阈值效率或采集参数；
- 通道响应状态。

因此，指数拟合的作用是给出一个经验尺度，而不是测量严格的材料常数。

##### 8. 误差处理

计数统计可近似服从泊松分布：

```math
\sigma_N\approx\sqrt{N}
```

计数率为：

```math
R=\frac{N}{T}
```

如果测量时间也存在不确定度`\sigma_T`，则计数率的相对误差可近似写成：

```math
\frac{\sigma_R}{R}
=
\sqrt{
\frac{1}{N}
+
\left(\frac{\sigma_T}{T}\right)^2
}
```

本实验取：

```math
T=3600\ \mathrm{s},\qquad
\sigma_T=60\ \mathrm{s}
```

因此时间相对误差为：

```math
\frac{\sigma_T}{T}
=
\frac{60}{3600}
\approx0.0167
```

也就是约`1.7%`。

##### 9. 分布图的诊断作用

除了统计符合数，还必须检查`area`和`area2`分布。原因是，符合数下降可能来自多类因素：

- 铅板真正改变了粒子通过和形成符合的概率；
- 探测器响应或采集参数发生变化；
- 固定阈值筛选是否对结果敏感。

本实验中，0片铅板条件下两周`area2`分布存在差异，可能与设备参数设置、积分尺度或采集状态有关。进一步改变阈值后，主要符合计数没有明显变化，说明固定阈值并未实际控制当前结果。因此，不能把两周差异简单归因于`area2`左移导致的有效效率下降。

因此，`area2`分布图不是附属图，而是判断跨周数据是否存在设备参数差异的重要诊断工具；但是否影响最终符合计数，必须由阈值扫描来验证。

一句话总结：

> 数据处理方法就是用固定阈值从ROOT事件数据中筛选双通道符合事件，计算每个铅板厚度下的符合计数率、相对透过率和阻挡率；再通过分周拟合、0片基准对比、`area2`分布检查和阈值扫描，区分铅板物理效应、设备参数差异和阈值敏感性。

#### 条件符合比的物理含义与近似推导

除绝对符合计数率`R_coin`外，还可以定义条件符合比：

```math
\frac{N_{\rm coin}}{N_{\rm up}}
```

其中：

```math
N_{\rm up}=\#(\mathrm{area}>30)
```

表示上探测器中通过阈值的事件数，而：

```math
N_{\rm coin}
=\#[(\mathrm{area}>30)\land(\mathrm{area2}>30)]
```

表示同时通过上下两个探测器阈值的符合事件数。

因此，条件符合比可以理解为一个条件概率：

```math
\frac{N_{\rm coin}}{N_{\rm up}}
\approx
P(\text{下探测器也记录到有效信号}\mid \text{上探测器已记录到有效信号})
```

也就是说，在已经被上探测器选出的候选宇宙线事件中，有多大比例还能到达下探测器并产生超过阈值的信号。

可以把上探测器通过阈值的事件数写成：

```math
N_{\rm up}\sim \Phi A_{\rm up}\epsilon_{\rm up}T
```

其中：

- `Phi`表示入射宇宙线通量；
- `A_up`表示上探测器有效面积；
- `epsilon_up`表示上探测器有效探测效率；
- `T`表示测量时间。

符合事件数则可以近似写成：

```math
N_{\rm coin}
\sim
\Phi A_{\rm up}\epsilon_{\rm up}T
\cdot A_{\rm geom}
\cdot \epsilon_{\rm down}
\cdot P_{\rm pass}(x)
```

这里：

- `A_geom`表示在上探测器已经触发的条件下，粒子方向和入射位置仍能使其穿过下探测器的几何接受因子；
- `epsilon_down`表示下探测器有效探测效率；
- `P_pass(x)`表示粒子穿过厚度为`x`的铅板后，仍能形成有效符合事件的概率。

两式相除，得到：

```math
\frac{N_{\rm coin}}{N_{\rm up}}
\sim
A_{\rm geom}\epsilon_{\rm down}P_{\rm pass}(x)
```

这个近似的好处是，入射通量`Phi`、上探测器面积`A_up`、上探测器效率`epsilon_up`和测量时间`T`在比值中被部分抵消。因此，条件符合比比绝对符合数更适合用来检查“上探测器触发后，下探测器确认能力是否改变”。

但是这个比值不能自动消除下探测器效率或采集参数变化。如果某一通道的阈值效率真的改变，条件符合比会随之变化；但本实验改变阈值后符合计数基本没有变化，说明当前`area2`分布差异并没有实际改变阈值通过效率。因此，条件符合比的跨周差异若存在，应优先结合几何摆放、通量变化、采集条件和整体设备状态分析，而不能简单归因于`area2`左移。

#### 双探测器宇宙线望远镜的几何接受角近似

海平面宇宙线`\mu`子来自上半空间，天顶角范围为：

```math
0^\circ\leq\theta\leq 90^\circ
```

整个上半空间的立体角为：

```math
2\pi\ \mathrm{sr}
```

但本实验不是接收整个上半空间的`\mu`子。上下两个塑料闪烁体探测器构成一个简易宇宙线望远镜，只有方向和位置合适、能够同时穿过上探测器和下探测器的`\mu`子，才可能形成符合事件。

SP5608塑料闪烁体的有效探测体积为：

```math
47\times47\times10\ \mathrm{mm^3}
```

因此横向有效边长可取：

```math
a=47\ \mathrm{mm}
```

设上下两个探测器中心对齐，中心间距为：

```math
L
```

若一个`\mu`子相对于竖直方向的天顶角为`\theta`，在上下探测器之间产生的横向位移近似为：

```math
\Delta r\simeq L\tan\theta
```

如果用最简单的圆锥近似，即认为从上探测器中心入射的粒子只要仍落在下探测器有效面积内就能形成符合，则要求：

```math
L\tan\theta\lesssim \frac{a}{2}
```

因此最大接受半角近似为：

```math
\theta_{\max}\simeq \arctan\left(\frac{a/2}{L}\right)
=\arctan\left(\frac{23.5\ \mathrm{mm}}{L}\right)
```

对应的近似接受立体角为：

```math
\Omega_{\rm acc}
\simeq
2\pi(1-\cos\theta_{\max})
```

这个结果说明，双探测器实际接收的不是`2pi sr`，而是一个由探测器横向尺寸和上下间距决定的有限立体角。上下距离`L`越大，`\theta_max`越小，装置越只接收接近竖直方向的`\mu`子；探测器横向尺寸`a`越大，`\theta_max`越大，几何接受范围越宽。

需要注意，这只是一个便于理解的圆锥近似。真实探测器的有效面积是正方形`47 mm x 47 mm`，因此真实几何接受度不是严格圆锥，而是由两个正方形在不同入射方向下的投影重叠面积决定。更严格的符合计数率应写成角度积分：

```math
R_{\rm coin}
\sim
\int I(\theta,\phi)
A_{\rm overlap}(\theta,\phi)
\epsilon_{\rm up}\epsilon_{\rm down}
P_{\rm pass}(x,E,\theta)
d\Omega\,dE
```

其中：

- `I(theta,phi)`表示宇宙线角分布；
- `A_overlap(theta,phi)`表示给定入射方向下，上下探测器有效面积的几何重叠；
- `P_pass(x,E,theta)`表示能量为`E`、方向为`theta`的粒子穿过厚度`x`铅板后仍能形成有效符合的概率。

常用近似中，海平面`\mu`子角分布可写为：

```math
I(\theta)\simeq I(0)\cos^2\theta
```

这表示竖直方向`\mu`子最多，越接近水平方向通量越低。因此，上下双探测器本身已经偏向选择接近竖直方向的`\mu`子。

加入铅板后，铅不仅可能削弱低能粒子，还会通过多重散射改变粒子方向。即使`\mu`子没有被铅完全吸收，只要散射后偏离几何接受范围，错过下探测器，也会使`N_coin`和`R_coin`下降。因此，本实验观测到的是“有效符合计数率”的下降，而不仅是粒子在铅中的真实吸收。

#### 几何错位对符合计数的量级估算

第二周0片铅板符合数明显低于第一周：

```math
\frac{N_{\rm coin}^{\rm W2}(0)}{N_{\rm coin}^{\rm W1}(0)}
=
\frac{1831}{3357}
\approx0.545
```

因此需要判断：上下探测器目视对准误差是否可能单独造成约`45%`的符合数下降。

##### 1. 竖直重叠面积近似

SP5608塑料闪烁体的横向有效边长为：

```math
a=47\ \mathrm{mm}
```

如果上下探测器在一个方向上横向错开`d`，并且只考虑近似竖直入射的粒子，则上下探测器的有效重叠长度从`a`变为：

```math
a-d
```

于是重叠面积比例近似为：

```math
\frac{A_{\rm overlap}}{A}
\approx
\frac{a-d}{a}
=
1-\frac{d}{a}
```

若希望符合数下降到原来的`0.5`，则有：

```math
1-\frac{d}{a}=0.5
```

所以：

```math
d=0.5a=23.5\ \mathrm{mm}
```

若要解释本实验第二周和第一周0片基准的比例`0.545`，则：

```math
1-\frac{d}{47}=0.545
```

得到：

```math
d\approx47(1-0.545)
\approx21.4\ \mathrm{mm}
```

也就是说，在单方向错位的竖直重叠面积近似下，需要约`21 mm`量级的横向错位，才能造成与观测值相近的符合数下降。这个错位已经接近探测器边长的一半，目视对准时通常应较容易察觉。

##### 2. 两个方向同时偏移的近似

如果上下探测器在`x`和`y`两个方向都偏移，且两个方向偏移量都为`d`，则重叠面积比例近似为：

```math
\frac{A_{\rm overlap}}{A}
\approx
\left(1-\frac{d}{a}\right)^2
```

令其等于`0.5`：

```math
\left(1-\frac{d}{47}\right)^2=0.5
```

得到：

```math
d=47(1-\sqrt{0.5})
\approx13.8\ \mathrm{mm}
```

这是每个方向各偏移约`13.8 mm`。对应总横向偏移为：

```math
r=\sqrt{d^2+d^2}
\approx19.5\ \mathrm{mm}
```

因此，即使两个方向同时错开，要造成约一半的几何重叠损失，总偏移量也大约在`20 mm`量级。

##### 3. 等效倾斜角近似

老师提到的“探测器偏离相当于把探测器倾斜一个角度”，可以用宇宙线望远镜轴线的偏转来理解。设上下探测器中心横向偏移为`d`，上下探测器中心间距为`L`，则中心接收方向相对竖直方向的等效倾角为：

```math
\theta_{\rm axis}
\simeq
\arctan\frac{d}{L}
```

海平面宇宙线`\mu`子角分布常近似为：

```math
I(\theta)\simeq I(0)\cos^2\theta
```

再考虑水平探测器的投影因子，符合计数率可粗略按：

```math
R(\theta)\propto \cos^3\theta
```

估算。若要使计数率降到原来的一半：

```math
\cos^3\theta=0.5
```

则：

```math
\theta\approx37.5^\circ
```

对应横向偏移为：

```math
d=L\tan37.5^\circ
\approx0.77L
```

如果上下间距为`50 mm`，则：

```math
d\approx38\ \mathrm{mm}
```

如果上下间距为`100 mm`，则：

```math
d\approx77\ \mathrm{mm}
```

这个估算说明，如果只从宇宙线角分布的等效倾斜角出发，要造成约一半计数下降，需要非常大的等效倾角和横向偏移，通常不像普通目视对准误差。

##### 4. 对本实验的判断

几何错位确实会影响双探测器符合计数，因为它会改变：

- 上下探测器的有效重叠面积；
- 宇宙线望远镜的中心接收方向；
- 有限立体角接受范围。

但是，要单靠几何错位把符合数降到：

```math
0.545
```

量级，通常需要约：

```math
d\sim20\text{--}23\ \mathrm{mm}
```

甚至更大的横向错位，具体取决于实际上下距离和偏移方向。这个量级已经接近SP5608探测器边长`47 mm`的一半。如果实验中只是目视粗略对准且没有明显大尺度偏移，则几何对齐误差可以作为系统误差来源讨论，但不太可能单独解释第二周0片符合数约`45%`的下降。

因此，第二周0片基准显著降低更可能与广义探测效率或采集效率变化有关，例如硬件触发条件、DAQ live time、采集模式、实际记录时间、电子学设置或运行状态变化。

#### 第二周40--60片绝对符合数回升的解释

第二周厚铅板区间的绝对符合数为：

```math
N_{\rm coin}(40)=1523
```

```math
N_{\rm coin}(50)=1579
```

```math
N_{\rm coin}(60)=1687
```

表面上看，40片到60片铅板的符合数随厚度增加反而上升。但这个现象不能直接解释为“铅板越厚越容易形成符合”，需要先以上探测器候选事件数进行归一化。

第二周预拟合表中给出的条件符合比为：

```math
\frac{N_{\rm coin}}{N_{\rm up}}(0)
=
0.2672\pm0.0053
```

```math
\frac{N_{\rm coin}}{N_{\rm up}}(40)
=
0.2324\pm0.0052
```

```math
\frac{N_{\rm coin}}{N_{\rm up}}(50)
=
0.2308\pm0.0051
```

```math
\frac{N_{\rm coin}}{N_{\rm up}}(60)
=
0.2307\pm0.0049
```

可以看出，从0片到40片，条件符合比明显下降；而从40片到60片，条件符合比基本保持不变。

##### 1. 0片到40片的下降是显著的

0片到40片的条件符合比差异为：

```math
0.2672-0.2324=0.0348
```

合成误差约为：

```math
\sqrt{0.0053^2+0.0052^2}
\approx0.0074
```

对应显著性为：

```math
\frac{0.0348}{0.0074}
\approx4.7\sigma
```

因此，第二周从0片到40片铅板时，有效符合概率确实发生了显著下降。这可以理解为铅板引入后，能量损失、多重散射和几何接受度损失共同降低了上探测器候选事件形成双探测器符合的概率。

##### 2. 40--60片区间更接近平台

40片到50片的条件符合比差异为：

```math
0.2324-0.2308=0.0016
```

合成误差约为：

```math
\sqrt{0.0052^2+0.0051^2}
\approx0.0073
```

显著性只有：

```math
\frac{0.0016}{0.0073}
\approx0.22\sigma
```

50片到60片的差异为：

```math
0.2308-0.2307=0.0001
```

几乎可以忽略。因此，40、50、60片铅板的条件符合比在误差范围内一致，更合理地理解为一个平台：

```math
\frac{N_{\rm coin}}{N_{\rm up}}
\approx0.231
```

这说明厚铅板区间并没有显示出可靠的继续下降趋势，也没有显示出可靠的物理回升趋势。

##### 3. 绝对符合数上升来自上通道候选事件规模变化

由于：

```math
N_{\rm coin}
=
N_{\rm up}
\times
\frac{N_{\rm coin}}{N_{\rm up}}
```

如果`N_coin`上升，但`N_coin/N_up`基本不变，那么`N_coin`的上升主要来自`N_up`增加，而不是每个上探测器候选事件形成符合的概率增加。

可由数据反推`N_up`的量级：

```math
N_{\rm up}(40)
\approx
\frac{1523}{0.2324}
\approx6553
```

```math
N_{\rm up}(50)
\approx
\frac{1579}{0.2308}
\approx6841
```

```math
N_{\rm up}(60)
\approx
\frac{1687}{0.2307}
\approx7313
```

因此，40片到60片之间：

```math
\frac{7313-6553}{6553}
\approx11.6\%
```

上探测器候选事件数增加约`11.6%`，而绝对符合数增加：

```math
\frac{1687-1523}{1523}
\approx10.8\%
```

二者非常接近。这说明40--60片绝对符合数回升主要来自上通道候选事件规模同步增加。

实验中部分run实际采集时间比一小时多约`1--2 min`。这可解释数个百分点的计数增加：

```math

```

```math
\frac{2}{60}\approx3.3\%
```

但不足以单独解释40片到60片约`10.8%`的绝对符合数上升。因此，其余差异可能来自短时间宇宙线通量涨落、上通道触发规模变化、DAQ有效记录率变化、电子学状态或环境条件变化等因素。

##### 4. 为什么不支持Rossi曲线式回升

如果40--60片的回升来自Rossi曲线相关的二次粒子产生效应，那么对于同样数量的上探测器候选事件，下探测器形成符合的概率应当增加。换言之，条件符合比：

```math
\frac{N_{\rm coin}}{N_{\rm up}}
```

应该随铅板厚度增加而上升。

但实际数据为：

```math
0.2324,\quad 0.2308,\quad 0.2307
```

从40片到60片并未上升，而是在误差范围内保持平台。因此，绝对符合数的回升不支持Rossi曲线式物理解释。

论文中可以使用如下表述：

```latex
第二周40、50、60片的绝对符合数分别为1523、1579和1687，表面上呈现随铅板厚度增加而回升。然而，对应的条件符合比分别为
\[
0.2324\pm0.0052,\quad
0.2308\pm0.0051,\quad
0.2307\pm0.0049,
\]
在误差范围内几乎一致。这说明40--60片区间的绝对符合数上升主要来自上探测器候选事件数 \(N_{\rm up}\) 的同步增加，而不是铅板厚度使有效符合概率增加。若该回升来自Rossi曲线相关的二次粒子产生效应，则 \(N_{\rm coin}/N_{\rm up}\) 也应随厚度增加而上升；当前数据没有显示这一特征。因此，40--60片区间更合理地解释为条件符合比平台，而不是材料物理导致的回升。
```

最终判断：

> 第二周40--60片绝对符合数回升不是可靠的铅板物理效应。用`N_coin/N_up`归一化后，厚铅板区间基本保持平台；绝对计数上升主要来自上探测器候选事件规模增加，可能与采集时长、通量涨落、上通道触发规模或DAQ有效记录率变化有关。

#### 铅板中的能量损失和多重散射

铅板对宇宙线`\mu`子的影响不能简单理解为“像墙一样挡住大量`\mu`子”。对于海平面常见的GeV量级`\mu`子，几十毫米铅板通常不足以使大多数`\mu`子完全停止。铅板更主要的作用是通过能量损失和多重散射改变粒子的能量、方向以及能否继续形成双探测器符合事件。

##### 1. 能量损失

带电粒子穿过物质时，会和物质中的原子电子发生电磁相互作用，使原子电离或激发。对于`\mu^+`或`\mu^-`，这个过程会使`\mu`子沿路径不断损失能量，通常称为电离能损。

电离能损常写成：

```math
-\frac{dE}{dx}
```

它表示粒子每穿过单位厚度材料时平均损失的能量。对于GeV量级的宇宙线`\mu`子，电离能损的典型量级约为：

```math
\frac{dE}{dx}\sim 1\text{--}2\ \mathrm{MeV/(g/cm^2)}
```

铅的密度约为：

```math
\rho_{\rm Pb}\approx 11.34\ \mathrm{g/cm^3}
```

第一周最大铅厚为`15 mm`，即：

```math
x=15\ \mathrm{mm}=1.5\ \mathrm{cm}
```

对应质量厚度为：

```math
\rho x\approx 11.34\times1.5
\approx 17.0\ \mathrm{g/cm^2}
```

因此能量损失量级为：

```math
\Delta E
\sim
(1\text{--}2)\times17
\approx
17\text{--}34\ \mathrm{MeV}
```

而海平面宇宙线`\mu`子的典型能量为GeV量级，例如：

```math
E_\mu\sim 1\text{--}4\ \mathrm{GeV}
```

也就是几千MeV。因此，十几毫米铅板造成的几十MeV能量损失，通常不足以完全阻止大部分GeV量级`\mu`子。这说明，不能把第一周约`9%`的有效符合率下降直接解释为“15 mm铅吸收了约9%的`\mu`子”。

更合理的说法是：

> 15 mm铅板使本实验装置记录到的双探测器有效符合事件减少约9%。

能损仍然会影响实验结果，原因是宇宙线`\mu`子不是单能粒子，而是具有连续能谱。高能`\mu`子更容易穿过铅板，低能`\mu`子更容易受能损影响。加入铅板后，一部分低能成分可能能量不足以继续到达下探测器，或者到达下探测器后产生的信号较弱，低于固定阈值`area2 > 30`，从而不再计入符合事件。

因此，能量损失主要影响：

- 低能`\mu`子成分；
- 到达下探测器后的信号强度；
- 固定阈值条件下的有效通过概率；
- `P_pass(x)`中与能量有关的部分。

##### 2. 多重散射

多重散射是铅板影响符合率的另一个关键机制。`\mu`子穿过铅时，会受到许多铅原子核库仑场的作用。单次偏转角通常很小，但大量小角度偏转累积后，粒子传播方向会发生随机偏离。这一过程称为库仑多重散射。

PDG常用的多重散射角近似公式为：

```math
\theta_0\simeq
\frac{13.6\ \mathrm{MeV}}{\beta pc}z
\sqrt{\frac{x}{X_0}}
\left[
1+0.038\ln\left(\frac{x}{X_0}\right)
\right]
```

其中：

- `theta_0`表示多重散射角分布的典型宽度，可近似理解为RMS散射角；
- `beta=v/c`，对GeV量级`\mu`子通常接近1；
- `p`表示粒子动量；
- `z`表示粒子电荷数，`\mu^\pm`有`|z|=1`；
- `x`表示材料厚度；
- `X_0`表示材料辐射长度。

铅的辐射长度约为：

```math
X_0\approx5.6\ \mathrm{mm}
```

这个公式说明：

```math
\theta_0\propto\frac{1}{p}
```

低动量粒子的散射更明显；

```math
\theta_0\propto\sqrt{x}
```

铅板越厚，散射角越大。由于铅是高`Z`、高密度材料，辐射长度较小，因此容易产生较明显的多重散射。

以第一周最大厚度`15 mm`为例：

```math
\frac{x}{X_0}\approx\frac{15}{5.6}\approx2.7
```

若取`\mu`子动量：

```math
p=1\ \mathrm{GeV}/c=1000\ \mathrm{MeV}/c
```

且`\beta\approx1`，则：

```math
\theta_0
\sim
\frac{13.6}{1000}\sqrt{2.7}
\left[1+0.038\ln(2.7)\right]
```

由于：

```math
\sqrt{2.7}\approx1.64
```

```math
1+0.038\ln(2.7)\approx1.04
```

所以：

```math
\theta_0
\sim
0.0136\times1.64\times1.04
\approx0.023\ \mathrm{rad}
```

换算成角度：

```math
0.023\ \mathrm{rad}\approx1.3^\circ
```

如果`\mu`子动量为`4 GeV/c`，由于散射角近似与`1/p`成正比，则散射角约为上述结果的四分之一，即约`0.3^\circ`。这说明低能或低动量`\mu`子更容易被铅板散射出原本的传播方向。

##### 3. 多重散射对双探测器符合的影响

本实验采用上下双探测器结构。没有铅板时，只要`\mu`子的入射方向位于宇宙线望远镜的几何接受范围内，它就可能同时穿过上下探测器并形成符合事件。

加入铅板后，即使`\mu`子没有被铅完全吸收，它也可能在铅中发生多重散射，导致传播方向改变。如果上下探测器中心距离为`L`，散射角为`\theta`，则在小角度近似下，横向偏移量约为：

```math
\Delta r\sim L\theta
```

如果这个横向偏移量接近或超过下探测器半宽：

```math
\frac{a}{2}=23.5\ \mathrm{mm}
```

粒子就可能错过下探测器，从而不再形成符合事件。

因此，多重散射降低的不是“粒子是否存在”，而是：

> 粒子是否仍然落在双探测器的几何接受范围内。

这也是为什么本实验中的有效衰减长度`\lambda_eff`不能解释为铅中`\mu`子的纯吸收长度。它包含了：

- 能量损失导致的低能成分削弱；
- 多重散射导致的几何损失；
- 探测器阈值导致的有效效率变化；
- 上下探测器有限几何接受度。

##### 4. 与本实验数据的关系

第一周数据中，铅板从0片增加到30片，即铅厚从`0`增加到`15 mm`，符合事件数从：

```math
3357
```

下降到：

```math
3046
```

对应有效透过率：

```math
\frac{3046}{3357}\approx0.907
```

有效符合率下降约：

```math
1-0.907\approx0.093
```

也就是约`9.3%`。这个下降可以理解为：

- 一部分低能`\mu`子或其他低能成分被铅板能损削弱；
- 一部分粒子经过铅板后发生多重散射，偏离下探测器；
- 一部分到达下探测器的事件可能由于信号较弱或阈值原因未能通过`area2 > 30`，但本实验阈值扫描表明该因素对当前计数影响不明显；
- 因此双探测器有效符合数下降。

但是，这个`9.3%`不是纯粹的`\mu`子吸收概率。即使阈值扫描表明`area2`分布差异对当前计数没有明显影响，本实验的观测量仍然包含材料作用、几何接受度、探测器效率和采集条件等因素。因此，论文中应把观测量称为“有效符合率”或“有效符合计数率”，而不是直接称为“宇宙线吸收率”。

一句话总结：

> 能量损失改变`\mu`子的能量，主要影响低能成分和阈值通过概率；多重散射改变`\mu`子的方向，主要影响它是否还能落入上下探测器的几何接受范围。本实验测到的符合率下降，是材料效应、几何接受度和探测器阈值共同作用的结果。

#### 物理图像、模型适用范围与Rossi曲线

论文中需要写出物理图像，但不宜写得过长。物理图像的作用是说明本实验测到的`N_coin`和`R_coin`到底代表什么，以及它们不能被解释成什么。

本实验可以理解为一个上下双探测器构成的宇宙线望远镜：

```text
宇宙线mu子从上方入射
  -> 穿过上探测器，产生area信号
  -> 经过铅板，发生能量损失和多重散射
  -> 如果仍位于几何接受范围内，则穿过下探测器
  -> 产生area2信号
  -> area > 30 且 area2 > 30 时，计为符合事件
```

因此，实验测量的不是单纯的“铅板穿透概率”，而是：

```math
N_{\rm coin}
=
\#[(\mathrm{area}>30)\land(\mathrm{area2}>30)]
```

它代表的是在本实验几何、探测器效率和固定阈值条件下，能够同时被上下探测器记录到的有效宇宙线事件数。

对应的符合计数率可形式上写为：

```math
R_{\rm coin}
\sim
\Phi A_{\rm geom}
\epsilon_{\rm up}\epsilon_{\rm down}
P_{\rm pass}(x)
```

其中：

- `Phi`表示入射宇宙线通量；
- `A_geom`表示上下探测器形成的几何接受度；
- `epsilon_up`和`epsilon_down`表示上下探测器有效探测效率；
- `P_pass(x)`表示铅厚为`x`时，粒子仍能形成有效符合的概率。

这个物理图像中最重要的一句话是：

> “穿过铅板”和“形成双探测器符合事件”不是同一个概念。

一个`\mu`子即使穿过了铅板，也可能因为多重散射偏离下探测器，或者因为下探测器脉冲积分量低于固定阈值而不被计入。因此，论文中更稳妥的说法是“有效符合率衰减”，而不是“`\mu`子吸收率”。

建议论文正文中把这部分压缩写入“实验原理与数据处理”或“实验原理与模型适用范围”，不需要单独展开成很长一节。可参考如下表述：

```latex
本实验的物理图像可理解为一个由上下两个闪烁体探测器构成的宇宙线望远镜。只有入射方向和位置满足几何条件的宇宙线粒子，才可能同时穿过上下探测器并形成符合事件。加入铅板后，粒子在铅中会发生电离能损和多重库仑散射。对于 GeV 量级的海平面 \(\mu\) 子，十几毫米到几十毫米铅板通常不足以造成大量完全吸收，但低能成分可能被削弱，多重散射也可能使粒子偏离下探测器。因此，本文测量的不是单纯穿透概率，而是在固定几何、固定阈值和实际探测器效率条件下的有效符合率。
```

指数拟合得到的有效衰减长度也应在这个物理图像下解释：

```latex
因此，指数拟合得到的 \(\lambda_{\rm eff}\) 只能理解为有效衰减长度，其中包含材料作用、几何接受度、多重散射和阈值效率等因素，不能视为铅中 \(\mu\) 子的纯吸收长度。
```

##### Rossi曲线是否需要讨论

Rossi曲线可以提到，但不建议作为本文主线。Rossi曲线通常讨论宇宙线计数率随吸收体厚度增加时可能出现的“先升后降”行为。前期上升通常与二次粒子产生有关，后期下降则与吸收、能损和散射损失有关。

要可靠讨论Rossi曲线，通常需要：

- 更密集、更连续的吸收体厚度扫描；
- 稳定的探测器效率和阈值条件；
- 对二次粒子贡献的专门分析；
- 对几何接受度和偶然符合的更严格控制。

当前数据不适合把Rossi曲线作为主要分析对象。第一周数据在`0--15 mm`铅厚范围内主要表现为有效符合率下降；第二周厚铅板区间虽然有非单调现象，但需要先排查几何摆放、通量变化、采集条件和跨周基准差异，不能直接解释为Rossi曲线。

论文中可以用如下谨慎表述：

```latex
本文暂不将 Rossi 曲线作为主要分析对象。Rossi 曲线通常要求稳定探测器条件、更多吸收体厚度点以及对二次粒子贡献的专门分析。当前数据首先显示的是薄铅板区间的有效符合率下降以及跨周基准差异；阈值扫描表明下通道阈值不是导致该差异的主要因素。因此本文重点讨论有效符合率和系统误差，而不对 Rossi 曲线作定量解释。
```

##### 关于`area2`分布差异和阈值扫描的判断

关于第二周`area2`分布是否“明显左移”，不能只凭肉眼看图下结论。更重要的是，即使分布形状或均值存在差异，也不能直接推出它影响了符合计数。必须通过阈值扫描判断计数是否对`area2`阈值敏感。

可以检查以下量：

- `area2`均值：`\langle area2\rangle`；
- `area2`中位数；
- `area2`主峰峰位；
- 通过固定阈值的比例：`#(area2 > 30)/N_total`；
- 条件符合比：`N_coin/N_up`；
- 阈值扫描结果：改变`area2`阈值后`N_coin`和`N_coin/N_up`是否变化；
- 两周0片铅板条件下`area2`分布的归一化直方图对比。

本实验改变阈值后发现主要计数基本没有变化。因此，即使`area2`分布存在视觉差异或均值差异，也应理解为设备参数设置、积分尺度或采集状态差异，而不是影响最终符合计数的主要物理或效率因素。

论文中可采用更准确的表述：

> 两周0片铅板条件下，下探测器`area2`分布存在一定差异，可能反映设备参数或积分尺度设置不同。但阈值扫描显示，改变`area2`阈值后符合计数基本不变，说明该差异对当前有效符合率结果没有实质影响。因此，跨周差异不应简单归因于`area2`左移或固定阈值效率变化。

这条结果很重要，因为它排除了一个可能的系统误差来源，使论文解释更稳健。

## 一、总体定位

这篇论文最适合定位为一篇“实验数据质量与系统误差意识较强的课程论文”，而不是一篇强调发现新规律的研究短文。文章真正有价值的地方不是给出一个很漂亮的衰减长度，而是：

1. 第一周数据在同一探测器状态下显示了有效符合率随铅板厚度增加而下降；
2. 第二周数据与第一周 0 片基准存在显著差异，说明跨周合并不能草率进行；
3. 阈值扫描显示改变 `area2` 阈值后主要符合计数基本不变，因此 `area2` 分布差异更可能是设备参数或积分尺度差异，而不是影响结果的主要阈值效率效应。

建议全文主线改成：

> 本实验测量的是固定阈值和固定几何条件下的双探测器有效符合率。第一周数据显示 0--15 mm 铅厚范围内有效符合率下降约 9%，可用经验指数模型描述；第二周数据与第一周 0 片基准存在显著差异，因此不能不加检验地直接拼接为同一条厚度曲线。进一步阈值扫描表明，改变下探测器 `area2` 阈值后符合计数基本不变，说明 `area2` 分布差异不是当前结果的主要控制因素。该结果说明，宇宙线吸收体实验中基准测量、几何条件、采集参数和物理模型同等重要。

## 二、建议标题

原题：

> 宇宙线穿过铅板后的有效符合率衰减研究

这个标题已经不错，但可以更像课程论文，也更准确：

推荐第 2 个。它把“系统误差分析”放进标题，能突出本文真正的亮点。

这个摘要的好处是：先给主结果，再给模型含义，再给系统误差，最后给最终结论。逻辑更清楚。

>
> 第二周数据虽然覆盖更厚铅板区间，但其 0 片基准符合数显著低于第一周，说明跨周数据存在不可忽略的系统差异。下探测器 \(\mathrm{area2}\) 分布也存在差异，但阈值扫描显示改变 \(\mathrm{area2}\) 阈值后符合计数基本不变，因此该分布差异不应被解释为导致结果变化的主要阈值效率效应。第二周 40--60 片数据仍不宜直接与第一周数据拼接为一条高精度材料衰减曲线；0 片基准缩放只能作为一阶展示和诊断方法，不能替代对几何摆放、采集条件和环境因素的系统控制。
>
> 本实验的主要结论是：在稳定探测条件下，铅板会降低双探测器有效符合率；而在跨周测量中，0 片基准差异提示需要谨慎处理系统条件。阈值扫描排除了 `area2` 阈值变化作为主要影响因素，使分析重心应转向铅板材料效应、几何接受度、采集条件和环境涨落。对于课程实验而言，这一结果不仅展示了宇宙线与物质相互作用的实验现象，也说明了基准测量、阈值敏感性检查和系统误差诊断在探测器实验中的关键作用。

### 5. SiPM前置实验怎么写

SiPM部分不要写得过长，但必须讲清楚它和后面宇宙线实验的关系。重点保留以下内容：


- 斜率`\Delta A`表示单光电子平均积分贡献，即单光电子增益；
- 增益改变峰间距；
- 光强改变各峰高度比例；
- 阈值改变低`area`事件保留比例。

最关键的桥梁句是：

> SiPM前置实验说明，固定`area`阈值并不是纯数学筛选，而与探测器增益、基线、电子学状态和采集参数有关。因此，在宇宙线实验中使用固定阈值定义符合事件时，必须检查结果是否对阈值选择敏感。

但由于后续阈值扫描发现改变阈值后符合计数基本不变，所以论文中不能再写“`area2`分布差异导致第二周符合数下降”。应写成：

> 两周`area2`分布存在一定差异，可能反映设备参数或积分尺度设置不同；但阈值扫描表明该差异对当前符合计数没有实质影响。

### 6. 第一周数据怎么作为主结果

第一周是最适合作为主物理结果的数据：

```math
N_{\rm coin}(0)=3357,\qquad
N_{\rm coin}(30)=3046
```

对应：

```math
\mathcal{T}(30)=\frac{3046}{3357}\approx0.907
```

有效符合率下降约：

```math
1-0.907=0.093
```

也就是约`9.3%`。

建议正文中加入显著性估算：

```math
\frac{3357-3046}{\sqrt{3357+3046}}
\approx3.9\sigma
```

推荐表述：

> 第一周数据表明，在0--15 mm铅厚范围内，双探测器有效符合率整体下降，下降幅度约为9.3%。该变化超过单纯泊松涨落的典型尺度，但相邻厚度点之间差异较小，因此不应对局部起伏作过度解释。

### 7. 第二周0片基准差异怎么解释

第二周0片基准为：

```math
N_{\rm coin}^{\rm W2}(0)=1831
```

第一周0片基准为：

```math
N_{\rm coin}^{\rm W1}(0)=3357
```

比例：

```math
\frac{1831}{3357}\approx0.545
```

差异显著性约为：

```math
\frac{3357-1831}{\sqrt{3357+1831}}
\approx21\sigma
```

这说明两周0片基准差异远大于计数统计涨落，不能把两周数据不加检验地直接拼接。

但现在需要注意：这个差异不应再简单归因于`area2`阈值效率。因为阈值扫描已经表明改变阈值后符合计数基本不变。

推荐写法：

> 两周0片铅板基准符合数相差显著，说明跨周测量条件存在不可忽略的系统差异。虽然`area2`分布存在一定差异，但阈值扫描显示符合计数对`area2`阈值不敏感，因此该分布差异不应被解释为导致基准差异的主要阈值效率效应。更可能的系统来源包括有效采集时间、DAQ live time、硬件触发条件、探测器工作状态、几何摆放和环境通量变化等。

### 8. 几何对齐怎么处理

几何对齐需要讨论，但不能夸大。

SP5608有效横向尺寸为：

```math
a=47\ \mathrm{mm}
```

如果只用竖直重叠面积近似，要使计数降到`0.545`，单方向横向错位需约：

```math
d\approx47(1-0.545)\approx21.4\ \mathrm{mm}
```

这已经接近探测器边长的一半。若实验只是目视粗略对准，且没有明显大尺度偏移，则几何错位可以作为系统误差来源，但不太可能单独解释约`45%`的基准下降。

推荐写法：

> 由于上下探测器采用目视对准，几何接受度变化不能完全排除。简单重叠面积估算表明，若要单靠横向错位使符合数下降到约0.545倍，需要约20 mm量级的错位，接近探测器横向尺寸的一半。因此，几何对齐误差可作为系统误差来源讨论，但不宜作为第二周0片基准显著降低的唯一解释。

### 9. 第二周40--60片回升怎么处理

绝对符合数为：

```math
N_{\rm coin}(40)=1523,\quad
N_{\rm coin}(50)=1579,\quad
N_{\rm coin}(60)=1687
```

表面上看是回升。但条件符合比为：

```math
0.2324\pm0.0052,\quad
0.2308\pm0.0051,\quad
0.2307\pm0.0049
```

这三点在误差范围内一致，说明40--60片区间不是物理回升，而是条件符合比平台。

关键逻辑：

```math
N_{\rm coin}
=
N_{\rm up}
\times
\frac{N_{\rm coin}}{N_{\rm up}}
```

当`N_coin`上升但`N_coin/N_up`不升时，说明绝对符合数上升主要来自`N_up`增加，也就是上探测器候选事件规模增加。

推荐正文写法：

> 第二周40、50、60片铅板的绝对符合数分别为1523、1579和1687，表面上呈现回升趋势。然而对应的条件符合比分别为 \(0.2324\pm0.0052\)、\(0.2308\pm0.0051\) 和 \(0.2307\pm0.0049\)，在误差范围内基本一致。这说明绝对符合数的回升主要来自上探测器候选事件规模变化，而不是铅板厚度使有效符合概率增加。因此，40--60片区间更合理地解释为条件符合比平台。

### 10. Rossi曲线要不要写

可以提，但只能作为排除性讨论，不能作为主结论。

如果Rossi曲线式二次粒子效应导致回升，那么归一化后的：

```math
\frac{N_{\rm coin}}{N_{\rm up}}
```

也应该随厚度上升。但实际40--60片的条件符合比没有上升，因此不支持Rossi曲线解释。

推荐写法：

> 厚吸收体中二次粒子产生可能在某些实验构型中导致Rossi曲线式非单调行为。但在本实验中，40--60片铅板的条件符合比并未随厚度增加而上升，因此绝对符合数回升不支持Rossi曲线式物理解释。本文仅将Rossi曲线作为背景现象提及，不作定量分析。

- LED脉冲进入SiPM，触发0、1、2、3等光电子峰。
- `area`是脉冲电压波形扣除基线后的积分，近似反映输出电荷。
- 峰位置与光电子峰序号满足近似线性关系：

```math
\mathrm{Area}_n=A_0+n\Delta A.
```

- 增益改变峰间距，光强改变峰高度比例，阈值改变低`area`区域的保留。
- 低`area`高峰应称为基座峰或pedestal peak，不等于纯基线。

最后要接到宇宙线实验：

> SiPM前置实验说明，固定`area`阈值具有明确的探测器物理含义。因此，在宇宙线实验中使用固定阈值定义符合事件时，应通过阈值扫描检查计数是否对阈值敏感。本实验阈值扫描显示，改变下通道`area2`阈值后主要符合计数基本不变，因此`area2`分布差异不应作为当前结果的主要原因。

### 8. 第一周结果怎么写

第一周是主结果。必须突出：

```math
N_{\rm coin}(0)=3357,\qquad N_{\rm coin}(30)=3046.
```

```math
\mathcal{T}(15\ \mathrm{mm})=\frac{3046}{3357}\approx0.907.
```

```math
1-\mathcal{T}\approx0.093.
```

建议加显著性：

```math
\frac{3357-3046}{\sqrt{3357+3046}}
\approx3.9\sigma.
```

写法：

> 从0片到30片铅板，第一周符合数减少311，若只考虑独立泊松计数，其差异约为\(3.9\sigma\)。这说明整体下降已经超过单纯统计涨落的典型尺度。不过相邻厚度点之间差异较小，因此不应对局部起伏作过度物理解释。

指数拟合可以报，但语气要弱：

> 指数模型只提供有效尺度，\(\lambda_{\rm eff}\)不能与铅中\(\mu\)子吸收长度直接比较。

### 9. 第二周数据怎么写

第二周要分成三层。

第一层：0片基准低于第一周。

```math
\frac{1831}{3357}\approx0.545.
```

这个差异很大，说明跨周绝对计数不能直接拼接。可以保留21σ判断：

```math
\frac{3357-1831}{\sqrt{3357+1831}}\approx21\sigma.
```

第二层：`area2`分布差异不是主因。

写法：

> 两周0片铅板条件下，`area2`分布存在一定差异，可能反映设备参数、积分尺度或采集状态不同。但阈值扫描显示，改变`area2`阈值后符合计数基本不变，因此该差异对当前有效符合率结果没有实质影响，不能将第二周基准降低简单归因于离线阈值效率变化。

第三层：40--60片绝对计数回升不是Rossi曲线。

必须写`Coin/Up`：

```math
0.2324\pm0.0052,\quad
0.2308\pm0.0051,\quad
0.2307\pm0.0049.
```

写法：

> 40、50、60片铅板的绝对符合数分别为1523、1579和1687，表面上呈现回升；但条件符合比在误差范围内基本一致，说明绝对计数回升主要来自上探测器候选事件数增加，而不是每个候选事件形成符合的概率增加。因此该现象不支持Rossi曲线式物理回升。

### 10. 几何对齐问题怎么写

你们是目视粗略对准，因此几何误差不能完全忽略。但量级估算显示，它不太可能单独解释45%左右的基准下降。

可写：

```latex
若上下探测器中心横向偏移为 \(d\)，探测器横向有效边长为 \(a=47\ \mathrm{mm}\)，在只考虑竖直入射的重叠面积近似下，
\[
\frac{A_{\rm overlap}}{A}\approx1-\frac{d}{a}.
\]
要使重叠面积降至观测比例 \(1831/3357\simeq0.545\)，需要 \(d\simeq21\ \mathrm{mm}\) 的单方向错位。若两个方向同时偏移，总偏移量也约为 \(20\ \mathrm{mm}\) 量级。这个错位接近探测器边长的一半，通常不是普通目视对准误差可以轻易造成的。因此，几何对齐可作为系统误差来源讨论，但不宜作为第二周基准下降的唯一解释。
```

### 11. Rossi曲线怎么处理

不要把Rossi曲线作为主线。可以在讨论末尾写一小段，目的是说明“为什么不讨论”。

可写：

```latex
本文暂不将Rossi曲线作为主要分析对象。Rossi曲线通常要求稳定探测器条件、更多吸收体厚度点以及对二次粒子贡献的专门分析。若40--60片区间的绝对计数回升来自Rossi曲线相关的二次粒子产生效应，则条件符合比 \(N_{\rm coin}/N_{\rm up}\) 也应随厚度增加而上升。然而第二周40、50、60片的条件符合比在误差范围内基本一致，因此当前数据不支持Rossi曲线式回升解释。
```

### 12. 结论建议替换稿

建议结论最终写成：

> 本文对宇宙线穿过铅板后的双探测器有效符合率进行了分周分析。第一周数据表明，在0--15 mm铅厚范围内，固定阈值符合数由3357降至3046，相对透过率降至0.907，说明铅板会降低本实验装置记录到的有效符合事件比例。经验指数拟合给出\(10^2\) mm量级的有效衰减长度，但该参数同时包含材料中的能量损失、多重散射、几何接受度和探测器阈值效率，不能视为铅中\(\mu\)子的纯吸收长度。
>
> 第二周0片基准符合数为1831，显著低于第一周0片的3357，说明跨周绝对计数不能不加检验地直接拼接。虽然两周下探测器\(\mathrm{area2}\)分布存在差异，但阈值扫描显示改变\(\mathrm{area2}\)阈值后符合计数基本不变，因此该分布差异不应被解释为导致结果变化的主要阈值效率效应。几何错位估算表明，若要仅由对齐误差造成约0.545的基准比例，需要约20 mm量级的横向偏移，普通目视对准误差不太可能单独解释该差异。因此，第二周基准降低更可能与广义探测效率、采集效率、运行条件或有效记录时间等系统因素有关。
>
> 对第二周厚铅板区间，40、50、60片的绝对符合数虽从1523升至1687，但条件符合比\(N_{\rm coin}/N_{\rm up}\)分别为\(0.2324\pm0.0052\)、\(0.2308\pm0.0051\)和\(0.2307\pm0.0049\)，在误差范围内基本一致。这说明绝对符合数的回升主要来自上探测器候选事件规模变化，而不是铅板厚度导致的有效符合概率增加，也不支持Rossi曲线式回升解释。因此，本实验的可靠结论应表述为：在稳定条件下铅板会降低双探测器有效符合率；跨周和厚铅板数据必须通过基准测量、条件归一化、阈值扫描和几何估算进行系统误差诊断。

不要写：

要写：

#### 宇宙线铅板实验原理与数据处理

必须明确：

```math
N_{\rm up}=\#(\mathrm{area}>30)
```

```math
N_{\rm down}=\#(\mathrm{area2}>30)
```

```math
N_{\rm coin}=\#[(\mathrm{area}>30)\land(\mathrm{area2}>30)]
```

其中`area`是上探测器，`area2`是下探测器。

符合计数率：

```math
R_{\rm coin}=\frac{N_{\rm coin}}{T}
```

相对透过率：

```math
\mathcal{T}(x)=\frac{R_{\rm coin}(x)}{R_{\rm coin}(0)}
```

阻挡率：

```math
\mathcal{B}(x)=1-\mathcal{T}(x)
```

还要写双探测器是有限接受角的宇宙线望远镜：

```math
\theta_{\max}\simeq\arctan\left(\frac{23.5\ \mathrm{mm}}{L}\right)
```

核心解释：

> “穿过铅板”和“形成双探测器符合事件”不是同一个概念。粒子即使穿过铅板，也可能因多重散射偏离下探测器或因探测链路效率原因未被计入符合事件。

关键数值：


```math
1-0.907=0.093
```

整体显著性：


1. 图只展示数据事实，不在图题中直接写因果结论。
2. 图题和图注使用中性表述，例如“面积分布比较”“条件符合比比较”“二维面积相关分布”。
3. 不使用 `problem`、`efficiency dropped`、`geometry loss`、`gain shift` 这类判断性标签。
4. 所有跨周比较必须明确写出比较对象，例如“第一周0片”和“第二周0片”，不能只写 last week / this week。
5. 若比较不同铅厚，应承认其中同时包含铅板物理效应和周次/设备状态差异，不能把差异直接归因于某一个探测器。

#### 建议重画图1：主结果图，有效符合率随铅厚变化

这张图应该是论文中最重要的结果图。

横轴：

```text
铅板厚度 x / mm
```

或者用铅板片数作为副坐标，但主坐标建议用厚度。若每片铅板厚度为0.5 mm，则：

```math
x=0.5\,n_{\rm plate}\ {\rm mm}
```

纵轴建议画两种中的一种：

```math
R_{\rm coin}=\frac{N_{\rm coin}}{t}
```

或

```math
\mathcal{T}(x)=\frac{N_{\rm coin}(x)}{N_{\rm coin}(0)}
```

如果采集时长不完全相同，优先画 \(R_{\rm coin}\) 或归一化后的 \(\mathcal{T}\)，不要只画绝对符合数 \(N_{\rm coin}\)。

图中应该把第一周和第二周分开：

- 第一周0、10、20、30片作为主要数据组；
- 第二周0、40、50、60片作为另一组，用不同颜色或不同点形表示；
- 不要用一条连续拟合曲线把两周数据强行连起来。

如果做指数拟合，只建议对第一周稳定条件下的数据拟合：

```math
R_{\rm coin}(x)=R_0 \exp(-x/\lambda_{\rm eff})
```

或者

```math
\mathcal{T}(x)=\exp(-x/\lambda_{\rm eff})
```

图注推荐写法：

> 双探测器有效符合率随铅板厚度的变化。第一周数据在0--15 mm范围内显示整体下降趋势；第二周数据由于0片基准与第一周存在显著差异，未与第一周合并拟合。

这张图要支持的判断是：第一周可作为稳定条件下的主结果，第二周不能直接拼入同一条衰减曲线。

#### 建议重画图2：第二周条件符合比图

这张图用于解释“40片以后绝对符合数上升”为什么不能直接解释为Rossi曲线或铅板导致符合率增加。

横轴：

```text
铅板片数 n 或铅板厚度 x / mm
```

纵轴：

```math
\frac{N_{\rm coin}}{N_{\rm up}}
```

其中 \(N_{\rm up}\) 是上探测器过阈值的候选事件数，\(N_{\rm coin}\) 是上下探测器同时过阈值的符合事件数。

必须在图上画误差棒。若把 \(N_{\rm coin}/N_{\rm up}\) 视为二项比例，统计误差可近似写为：

```math
\sigma_p=\sqrt{\frac{p(1-p)}{N_{\rm up}}},\qquad p=\frac{N_{\rm coin}}{N_{\rm up}}
```

第二周关键数值应在正文或图注中给出：

```math
0.2324\pm0.0052,\quad
0.2308\pm0.0051,\quad
0.2307\pm0.0049
```

分别对应40、50、60片。

图注推荐写法：

> 第二周数据的条件符合比 \(N_{\rm coin}/N_{\rm up}\)。40、50、60片铅板条件下该比值在误差范围内基本一致，说明绝对符合数回升主要不来自符合概率上升。

这张图要支持的判断是：40--60片是条件符合比平台，而不是材料物理导致的明显回升。

#### 建议重画图3：下探测器 `area2` 分布诊断图

这张图可以放在系统误差分析部分，或者如果论文篇幅有限，只放在补充材料/附录中。它的作用不是证明“下探测器效率下降”，而是说明跨周数据的探测器响应或采集状态可能不同。

推荐只画两个面板。

左图：归一化 `area2` 直方图。

横轴：

```text
area2
```

纵轴：

```text
normalized counts 或 probability density
```

比较对象优先选：

- 第一周0片；
- 第二周0片。

如果必须比较第一周0片和第二周40片，图注必须说明该比较同时包含铅板厚度差异和周次差异，因此只能作为诊断，不能直接归因。

图中可以画一条竖直虚线：

```math
\mathrm{area2}=30
```

但虚线标签只写“analysis threshold”或“分析阈值”，不要写“cut causes loss”之类的结论。

右图：`area2` 阈值扫描。

横轴：

```text
area2 threshold
```

纵轴可以画：

```math
N_{\rm coin}(A_{\rm th})/N_{\rm coin}(30)
```

或者画不同阈值下的 \(N_{\rm coin}\)。

如果我们已经确认改变阈值后计数基本不变，那么这张图应该表现为近似平台。正文应写：

> 阈值扫描显示，合理范围内改变 `area2` 阈值后符合计数基本不变，因此 `area2` 分布差异不构成本实验结果的主要阈值效率来源。

这张图要支持的判断是：`area2` 分布可以作为系统差异的迹象，但不能解释成主要阈值效应。

#### 建议重画图4：上下探测器二维面积相关图

这张图信息量很高，但正式论文中要简化。建议画成2个或3个面板，不要放6个面板的大诊断拼图。

推荐版本：

- 左图：第一周0片的 `area`--`area2` 二维分布；
- 中图：第二周0片或第二周40片的 `area`--`area2` 二维分布；
- 右图可选：在 `area>30` 条件下的 `area2` 分布。

横轴：

```text
upper detector area
```

纵轴：

```text
lower detector area2
```

图中画两条虚线：

```math
\mathrm{area}=30,\qquad \mathrm{area2}=30
```

四个象限的含义可以在正文解释，不要全部写在图内：

- 右上：上下均过阈值，是符合事件区域；
- 右下：上探测器过阈值、下探测器未过阈值，是符合损失的候选区域；
- 左上：下探测器过阈值、上探测器未过阈值；
- 左下：双通道均低于阈值。

图注推荐写法：

> 上下探测器脉冲面积的二维相关分布。虚线表示分析阈值 \(\mathrm{area}=30\) 和 \(\mathrm{area2}=30\)。右上象限对应双通道符合事件，右下象限对应上探测器过阈值但下探测器未过阈值的事件。

如果右下象限在第二周或厚铅板条件下明显增加，正文中只能写成：

> 该现象提示符合损失可能与下游接受度、散射、探测器响应或采集链条件有关。

不要写成：

> 该图证明下探测器效率下降。

也不要写成：

> 该图证明几何损失是唯一原因。

#### 哪些图不建议放进论文

不建议放以下类型的图：

1. 带有 “efficiency dropped 54%” 这类结论性标题的图。
2. 带有 “problem detector” 这类主观标签的图。
3. 把第一周0片和第二周40片直接比较、却不说明厚度差异的图。
4. 过于拥挤的6面板诊断图。课程论文中读者更需要清楚的主结果图和少量关键诊断图。
5. 只显示绝对符合数、但不处理采集时长或 \(N_{\rm up}\) 变化的图。

#### 最终建议的论文图表组合

如果论文篇幅有限，建议保留3张核心图：

1. 第一周与第二周分开的有效符合率图，第一周拟合 \(\lambda_{\rm eff}\)。
2. 第二周40--60片的 \(N_{\rm coin}/N_{\rm up}\) 条件符合比图。
3. `area2` 阈值扫描或 `area`--`area2` 二维相关图，二选一作为系统误差诊断。

如果篇幅允许，可以保留4张：

1. 有效符合率主结果图；
2. 条件符合比图；
3. `area2` 分布与阈值扫描图；
4. 上下探测器二维面积相关图。

正文中的图像叙述顺序应是：

```text
主结果趋势
→ 第二周不能直接拼接的原因
→ 条件符合比排除40--60片物理回升
→ 诊断图说明系统误差来源复杂
```

最终写作原则：

> 图像不替我们下结论，图像只把数据事实清楚展示出来；真正的物理判断放在正文中，并且用“支持”“提示”“不能排除”“不宜解释为”等谨慎表述。
