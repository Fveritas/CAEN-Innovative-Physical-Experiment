# 宇宙线铅板阻挡实验数据分析规划

## 1. 实验背景

### 1.1 实验目的
本实验旨在通过测量宇宙射线穿过不同厚度铅板后的符合计数率变化，研究宇宙射线（主要是μ子）与物质的相互作用特性。主要物理目标包括：

1. **测量宇宙射线速度**：利用上下探测器的时间差和已知间距计算粒子速度（已验证现有实验仪器参数无法测量，可以略过）
2. **绘制Rossi转换曲线**：研究符合率随铅板厚度的变化规律
3. **研究粒子衰减特性**：分析粒子在铅中的能量损失和多重散射效应(主要内容)
4. **能量谱分析**：研究宇宙射线μ子的能量分布特征

### 1.2 实验装置

**探测器系统**：
- 上探测器：闪烁体 + 光电倍增管(PMT)
- 下探测器：闪烁体 + PMT
- 探测器尺寸：约10×10 cm²
- 探测器间距：16.2 cm（部分实验为50 cm）

**数据采集系统**：
- 数字化仪：CAEN DT5742
- 采样率：5 GHz (5 GS/s)
- 采样间隔：0.2 ns
- 波形长度：1024个采样点（204.8 ns）
- 分辨率：12-bit
- 触发模式：符合触发或单探测器触发

**铅板配置**：
- 材料：纯铅（纯度>99%，表面有2mm涂层，涂层近似没有阻挡宇宙线的能力）
- 单片厚度：0.5 mm
- 铅密度：ρ = 11.34 g/cm³
- 辐射长度：X₀ = 5.6 mm
- 放置位置：两探测器之间
- 对准精度：±1 mm（指铅板相对于探测器中心轴的横向位置偏差，确保宇宙射线穿过铅板和探测器的有效区域。此参数影响几何接收角和符合效率，数据存疑待确认）

## 2. 数据结构

### 2.1 ROOT文件内容

每个ROOT文件包含一个Tree (`t1`)，记录每个事件的以下变量：

- `area`：上探测器脉冲积分（与沉积能量成正比）
- `area2`：下探测器脉冲积分（与沉积能量成正比）
- `Index_minamp1`：上探测器波形最小值位置（时间信息）
- `Index_minamp2`：下探测器波形最小值位置（时间信息）
- `minamp1`：上探测器最小幅度
- `minamp2`：下探测器最小幅度

### 2.2 数据规模

- 每个文件：约50,000 - 200,000个事件
- 测量时间：1小时
- 触发率：约14-56 Hz
- 文件大小：100-165 MB

### 2.3 数据质量评估

#### 第一周数据（Week 1）

**5181.root（0片铅板，第一周基准）**：
- 符合率最高（~3357 counts/h）
- 数据质量优秀
- 用作第一周数据的归一化基准

**5182-5184.root（10-30片，第一周）**：
- 符合率逐渐下降
- 内部系统性一致
- 数据质量良好
- 可与5181.root直接比较

#### 第二周数据（Week 2）

**51811.root（0片铅板，第二周基准）**：
- 第二周的基准测量
- 用作第二周数据的归一化基准
- 与5181.root存在系统偏移，需要归一化比较

**5185-5187.root（40-60片，第二周）**：
- 符合率显著下降（铅板厚度大）
- 存在系统偏移（下探测器效率降低~10-15%）
- 需要归一化处理
- 不能与第一周数据直接比较绝对计数率

#### 跨周比较注意事项

- 两周测量之间可能存在的系统性差异来源：
  - PMT增益随温度变化
  - 高压稳定性影响
  - 探测器位置微调
  - 环境本底变化
- 建议使用相对测量方法（Coin/Up ratio）进行跨周比较
- 两个0片铅板数据（5181.root vs 51811.root）的比较可以量化系统漂移

## 3. 分析流程规划
### 3.1 数据预处理

**步骤1：数据读取与验证**
- 使用uproot库读取ROOT文件
- 检查数据完整性和Tree结构
- 验证事件数和变量范围
- 识别异常值和坏事件

**步骤2：数据诊断**
- 绘制area和area2的2D分布图
- 分析单探测器触发分布
- 评估噪声水平和阈值
- 检查时间差分布的合理性

**步骤3：阈值优化**
- 基于2D分布确定最优阈值
- 平衡信号效率和本底抑制
- 建议阈值：area > 30, area2 > 30
- 验证阈值对不同数据集的适用性

### 3.2 符合事件选择

**符合条件定义**：
```python
coincidence = (area > area_threshold) & (area2 > area2_threshold)
```

**关键参数**：
- 上探测器阈值：area_threshold = 30
- 下探测器阈值：area2_threshold = 30
- 时间窗口：由采样率决定（0.2 ns精度）

**符合率计算**：
- 符合事件数 / 测量时间
- 单位：counts/hour 或 Hz
- 统计误差：σ = √N（泊松统计）

### 3.3 物理量提取

**3.3.1 宇宙射线速度测量**

时间差计算：
```python
time_diff_ns = (Index_minamp2 - Index_minamp1) * 0.2  # 采样间隔0.2 ns
```

速度计算：
```python
distance_cm = 16.2  # 探测器间距
velocity = distance_cm / (time_diff_ns * 1e-9) / c  # 以光速为单位
```

预期结果：v ≈ 0.99c（相对论性μ子）

**3.3.2 Rossi转换曲线**

绘制符合率vs铅板厚度：
- X轴：铅板厚度（mm或辐射长度X₀）
- Y轴：符合率（counts/hour）
- 理论预期：在2-3 X₀处可能出现Rossi峰（由于次级粒子产生）
- 实际观测：主要表现为单调衰减（多重散射主导）

**3.3.3 衰减系数测量**

拟合指数衰减模型：
```
N(x) = N₀ * exp(-x/λ)
```
其中：
- N(x)：厚度x处的符合率
- N₀：无铅板时的符合率（5181.root）
- λ：有效衰减长度

**3.3.4 能量谱分析**

- 绘制area和area2的能量分布
- 分析能谱随铅板厚度的变化
- 研究低能粒子的优先衰减
- 评估能量阈值效应

### 3.4 系统效应修正

**时间依赖效应**：
- 不同周次测量的系统偏移
- PMT增益随温度变化
- 高压稳定性影响

**归一化方法**：
- 使用Coin/Up ratio（符合率/上探测器触发率）
- 相对于基准测量（5181.root）归一化
- 跨周数据比较时需要额外修正

**几何效应**：
- 探测器对准精度（±1 mm）
- 铅板放置位置的影响
- 立体角变化

## 4. 预期结果与物理解释

### 4.1 宇宙射线速度

**预期值**：v ≈ 0.99c

**物理解释**：
- 海平面宇宙射线主要是μ子
- μ子是相对论性粒子（动能 >> 静止质量）
- 典型能量：1-10 GeV
- 洛伦兹因子：γ ≈ 10-100

### 4.2 Rossi转换曲线

**理论预期**：
- 薄铅板：符合率下降（多重散射）
- 中等厚度（2-3 X₀）：可能出现Rossi峰（次级粒子产生）
- 厚铅板：继续下降（能量损失和吸收）

**实际观测**：
- 主要表现为单调衰减
- Rossi峰不明显（探测器几何限制）
- 多重散射是主导效应

### 4.3 衰减特性

**主要机制**：
1. **多重散射**：粒子偏离原方向，逃出探测器接收角
2. **电离能量损失**：dE/dx ≈ 2 MeV/(g/cm²)
3. **韧致辐射**：高能电子的额外能量损失
4. **核相互作用**：强子成分的吸收

**有效衰减长度**：
- 预期：λ ≈ 10-20 cm（取决于主导机制）
- 比纯吸收长度短（多重散射效应）

### 4.4 能量谱演化

**无铅板（5181.root）**：
- 典型μ子能谱
- 峰值在中等能量
- 高能尾部延伸

**增加铅板厚度**：
- 低能粒子优先被阻挡
- 能谱向高能偏移
- 总计数率下降

## 6. 注意事项与挑战

### 6.1 数据质量问题

- 不同周次测量的系统偏移
- 下探测器效率变化（5185-5186）
- 需要仔细的归一化处理

### 6.2 统计误差

- 1小时测量：N~3000, σ~55 (1.8%)
- 相对误差较小
- 系统误差可能占主导

### 6.3 物理解释的复杂性

- 多种物理过程同时作用
- Rossi峰可能不明显
- 需要蒙特卡罗模拟辅助理解

### 6.4 分析策略

#### 周内分析（同一周数据）
- **第一周数据**：使用5181.root作为基准，分析5182-5184的衰减规律
- **第二周数据**：使用51811.root作为基准，分析5185-5187的衰减规律
- 周内数据可以直接比较绝对计数率

#### 跨周分析（两周数据合并）
- 使用归一化方法：Coin/Up ratio（符合率/上探测器触发率）
- 评估系统漂移：比较5181.root和51811.root的差异
- 合并两周数据绘制完整的Rossi曲线（0-60片铅板）
- 充分评估不确定度来源

#### 速度测量专用
- 使用5181b.root（已校准时间信息）
- 专门用于宇宙射线速度的精确测量
- 时间差分析和飞行时间计算
